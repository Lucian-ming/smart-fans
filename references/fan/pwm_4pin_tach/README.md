# 4-Pin PWM 风扇与测速 (Intel 标准) 参考

## 1. 4-Pin 风扇引脚标准（Intel 规范）

| 引脚号 | 颜色线（常见） | 信号名称 | 电平与规范 |
| --- | --- | --- | --- |
| 1 | 黑 / 灰 | GND | 地 |
| 2 | 黄 / 红 | +12V DC | 电源供电（持续 12V，不在此处斩波） |
| 3 | 绿 / 黄 | TACH (FG) | 转速反馈，开漏输出，每转发出 2 个脉冲，需上拉到 3.3V |
| 4 | 蓝 | PWM | 控制信号，标准目标频率 **25 kHz**（允许 21~28 kHz），5V 逻辑电平 |

## 2. STM32 定时器参数配置

- **PWM 生成（TIM2_CH1，PA0）**：
  - 定时器输入时钟 = 72 MHz
  - 预分频器（PSC）= 71 → 计数频率 1 MHz
  - 自动重装载值（ARR）= 39 → PWM 周期 = (39+1) × 1 µs = 40 µs → **25.0 kHz**
  - 占空比 CCR 范围：0 ~ 40（对应 0% ~ 100%）

- **FG 测速计算（TIM1_CH1，PA8，输入捕获）**：
  - 风扇每旋转一周发出 2 个 FG 下降沿脉冲。
  - 设测得两次脉冲间隔时间为 $\Delta t$（秒），则瞬时转速：
    $$\text{RPM} = \frac{60}{2 \times \Delta t} = \frac{30}{\Delta t}$$
  - 或在 1 秒定时窗内统计脉冲计数值 $N$：
    $$\text{RPM} = \frac{N}{2} \times 60 = 30 \times N$$
