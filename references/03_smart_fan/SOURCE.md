# Smart Fan 智能风扇 (Reference 3)

- **项目链接**：[立创开源硬件平台 - Smart Fan 智能风扇](https://oshwhub.com/fishee/smartfan-intelligent-fan)
- **作者**：fishee
- **开源协议**：GPL 3.0
- **主控芯片**：STM32F103C8T6 (LQFP-48)

---

## 1. 核心架构与功能特点

1. **主控与传感器**：
   - 采用 STM32F103C8T6 作为主控。
   - 选用 **DS18B20** 数字单总线温度传感器进行环境温度采集（测温精度 ±0.5 ℃，抗干扰能力强于 NTC 模拟采样）。
2. **语音模块**：
   - 采用 **SU-03T** / SU-30T 离线语音识别模块。
   - 通过 UART 串口与 STM32 交换控制指令，无需外围音频电路，集成度高。
3. **显示方案**：
   - 采用彩色小尺寸 TFT 液晶屏，显示温度、风速等级、倒计时定时器状态。
4. **控制逻辑**：
   - 支持三种典型模式：**手动模式 (Manual)**、**定时模式 (Timer)**、**温控模式 (Auto-Temp)**。
   - 带有蓝牙透传模块，支持手机 App 进行调速与定时控制。

---

## 2. 对本项目的参考价值

1. **DS18B20 单总线时序实现**：
   - 该项目提供了标准的 STM32 微秒级延迟与 GPIO 开漏/输入输出动态切换的 DS18B20 驱动代码，可直接用于本项目的温度采集模块。
2. **三模状态机架构**：
   - 手动 / 定时 / 自动温控 的状态切换机制与防抖逻辑，是本项目固件应用层状态机设计的直接模板。
3. **SU-03T 语音方案对照**：
   - 可作为天问 ASR-PRO 之外的第二语音方案备选（引脚兼容 3.3V/5V TTL 串口）。
