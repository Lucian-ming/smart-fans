# ASR-PRO / 天问语音方案参考

## 1. 硬件连接

- 供电：5V（由板载 XL1509 DCDC 提供），瞬态播音峰值电流可达 0.5A~1A。
- 通信：UART 串口（TTL 3.3V / 5V 兼容），本项目统一接 STM32 的 USART2（PA2: TX, PA3: RX），波特率 115200。
- 音频输入输出：板载驻极体 MIC + 2P 扬声器插座（接 8Ω 2W 或 4Ω 3W 腔体喇叭）。

## 2. 串口协议格式与指令字典

ASR-PRO 采用天问图形化编程平台生成固件（工程文件已存放于 `references/01_bishe_voice_fan/firmware/Voice_Fan/基于天问开发平台语音程序/智能语音风扇.hd`）。

### 语音识别触发（ASR-PRO -> STM32）
通过串口发送换行结尾的字符串指令：
- `FON\r\n`：开启风扇
- `FOFF\r\n`：关闭风扇
- `F+\r\n`：风速提高 10%
- `F-\r\n`：风速降低 10%
- `FMAX\r\n`：风速最高
- `FMOD\r\n`：中等风速 (50%)
- `FMIN\r\n`：最低风速 (10%)
- `LON\r\n` / `LOFF\r\n`：开启 / 关闭照明

### 单片机应答确认（STM32 -> ASR-PRO 播报）
单片机接收并处理后，通过串口返回确认字符串触发模块语音回复：
- `Fyes` -> 触发模块播报“风扇开启成功”
- `Foff` -> 触发模块播报“风扇已关闭”
- `Lyes` -> 触发模块播报“照明开启成功”
- `Loff` -> 触发模块播报“照明已关闭”
