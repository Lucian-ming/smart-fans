# DS18B20 单总线数字温度传感器参考

## 1. 硬件连接
- 通信协议：Dallas 1-Wire（单总线）
- 引脚连接：DQ 接 STM32 PA1（配置为开漏输出 + 外部 4.7kΩ 上拉电阻到 3.3V）
- 测温精度：±0.5℃（在 -10℃ 至 +85℃ 范围内），出厂已校准，抗干扰能力优于模拟 NTC。

## 2. 核心操作时序（微秒延时驱动）
- 复位脉冲：MCU 拉低 DQ 至少 480 µs，释放总线等待 15~60 µs，读取存在脉冲（DS18B20 拉低 60~240 µs）。
- 写 0 / 写 1：写时隙至少 60 µs。
- 读 0 / 读 1：读时隙 15 µs 内采样总线电平。
- 转换指令：跳过 ROM (`0xCC`) -> 启动温度转换 (`0x44`) -> 延时等待（12位分辨率约需 750 ms，或非阻塞轮询） -> 读取暂存器 (`0xBE`)。
