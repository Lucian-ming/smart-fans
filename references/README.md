# references/ 参考例程

收集官方与社区的例程、Demo、配置工程，供移植时对照。**不参与编译**：这里的代码不会被 `firmware/` 引用，也不进 `lib_deps`。

## 目录

| 目录 | 放什么 |
| --- | --- |
| [speech/](speech/) | 离线语音模块（SU-03T / ASR-PRO / LD3320）的配置工程与串口例程 |
| [gesture/](gesture/) | 手势传感器（PAJ7620U2 / APDS-9960）驱动与手势识别例程 |
| [oled/](oled/) | OLED（SSD1306/SH1106）显示、U8g2 配置、中文字库 |
| [temperature/](temperature/) | DS18B20 单总线、NTC 查表、温度滤波算法 |
| [fan/](fan/) | PWM 调速、FG 测速、4-pin 风扇时序与软启动 |
| [system/](system/) | STM32 时钟、串口、Flash 模拟 EEPROM、看门狗等基础例程 |

## 收录规范

每个例程单独一个子目录，并且**必须**带 `SOURCE.md`：

```markdown
# 例程名称

- 来源：<原始链接>
- 作者 / 组织：
- 许可证：MIT / Apache-2.0 / 未标注（未标注则仅作参考，不直接复制）
- 适用：芯片型号 / 模块型号 / 库版本
- 能否直接编译：是 / 否（缺什么）
- 与本项目的差异：接口、时钟、引脚
```

需要改动才能用时，改动写同目录 `NOTES.md`，**不要直接改原例程**，方便日后对照。

## 使用流程

1. 先在原环境跑通，确认现象正确
2. 抽出与本项目相关的最小片段（通常 < 200 行）
3. 按 `firmware/` 的分层重写进 `hal/` 或 `drivers/`，不要整段复制粘贴
4. 在 `docs/logs/` 记录：用了哪个例程、改了什么、遇到什么坑

## 体积控制

- 只放源码与配置，删掉编译产物（`build/`、`Debug/`、`.pio/`、`*.o`）
- 大于 5 MB 的工程不要整包放进来：放链接 + 关键文件
- 带商用字体/音源等第三方资源的，确认许可证后再放
