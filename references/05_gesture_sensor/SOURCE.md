# 手势传感器方案参考 (Reference 5)

- **参考项目 1**：[IntelliFan - Smart Portable Fan (Hackster.io)](https://www.hackster.io/de-anza-college/intellifan-smart-portable-fan-psoc-6-ai-evaluation-kit-98e096)
- **核心手势方案**：**PAJ7620U2**（原相 PixArt 光学手势识别传感器）
- **通信接口**：标准 I²C（从机地址 `0x73`，8位写地址 `0xE6`，8位读地址 `0xE7`）
- **供电电压**：2.8V ~ 3.3V

---

## 1. PAJ7620U2 核心能力与手势类型

PAJ7620U2 集成了红外发光管（IR LED）与光学传感阵列，内置手势识别算法引擎，可直接输出识别结果，单片机无需进行复杂的图像或测距运算：

| 手势代码 | 手势动作 | 推荐映射到智能风扇的功能 |
| --- | --- | --- |
| `0x0001` | **向上挥手 (Up)** | 风速增加一档 (+10% / +1 档) |
| `0x0002` | **向下挥手 (Down)** | 风速降低一档 (-10% / -1 档) |
| `0x0004` | **向左挥手 (Left)** | 切换模式（手动模式 ↔ 自动温控模式） |
| `0x0008` | **向右挥手 (Right)** | 切换摇头/固定送风 或 开启/关闭照明 |
| `0x0010` | **向前靠近 (Forward/Push)** | 立即开启风扇（开机） |
| `0x0020` | **向后远离 (Backward/Pull)** | 立即关闭风扇（待机） |
| `0x0040` | **顺时针旋转 (Clockwise)** | 风速快速调至最大 (Max Speed) |
| `0x0080` | **逆时针旋转 (Counter-Clockwise)** | 风速调至最低 (Min Speed) |
| `0x0100` | **连续挥手 (Wave)** | 蜂鸣提示 / 屏幕点亮与唤醒 |

## 2. 硬件连接与设计注意事项

```
STM32F103C8T6                 PAJ7620U2 模块
 ┌─────────────┐             ┌─────────────┐
 │    PB6 (SCL)├────────────▶│ SCL         │ (与 0.96 OLED 共用 I2C1 总线)
 │    PB7 (SDA)├────────────▶│ SDA         │ (外接 4.7kΩ 上拉电阻到 3.3V)
 │    PA4 (EXTI)◀────────────┤ INT         │ (开漏输出，下降沿中断触发)
 │        3.3V ├─────────────┤ VDD         │
 │         GND ├─────────────┤ GND         │
 └─────────────┘             └─────────────┘
```

> [!IMPORTANT]
> 1. **I²C 地址独立**：0.96 寸 SSD1306 OLED 地址为 `0x3C`，而 PAJ7620U2 地址为 `0x73`，挂在同一条 I2C1 总线上完全无冲突。
> 2. **中断与轮询**：建议将 INT 引脚接单片机 PA4（配置为下降沿中断或外部中断 EXTI4）。检测到有效手势时，PAJ7620U2 会将 INT 拉低，MCU 进入中断后置位标志，主循环再通过 I2C 读取 `0x43/0x44` 寄存器获取手势值，避免在中断中占用 I2C。
> 3. **3D 外壳光学开窗**：PAJ7620U2 感应距离为 5 cm ~ 20 cm。3D 外壳前面板需为其预留一个直径约 6~8 mm 的圆形透光孔，或者透红外亚克力窗口，不可被普通不透明塑料外壳遮挡。
