# 通信协议（v1）

> 版本：v1.0 · 2026-11-03
> v1 **不联网**：设备只提供 UART1 文本命令接口，供调试、产测与可选的上位机使用。
> 若后续做 v2 联网（Wi-Fi/BLE），在本文件追加章节，不要改掉 v1 命令语义。

## 1. 物理层

| 项 | 值 |
| --- | --- |
| 接口 | UART1：PA9 (TX) / PA10 (RX)，3.3 V TTL |
| 参数 | 115200 8N1，无流控 |
| 行结束 | `\r\n` |
| 单行上限 | 128 字节（超长丢弃并回 ERR） |

## 2. 设备 → 上位机

**命令应答**

```
OK                                   # 无返回值的成功
OK temp=26.4 mode=auto speed=45 rpm=1180
ERR <code> <message>                 # 失败，code 见第 4 节
```

**异步事件**（状态变化或周期上报，默认 1 Hz，可开关）

```
EVT temp=26.4 speed=45 rpm=1180 mode=auto fault=none
EVT fault=stall                      # 故障发生时立即推送
EVT voice=speed_up                   # 语音词条识别结果（词条 id 映射见固件配置）
EVT gesture=left                     # 手势事件：up/down/left/right/cw/ccw/...
```

设备侧对每个词条/手势都应有明确的动作映射，映射表放在固件的 `app/` 配置里，不要写死在驱动层。

字段为 `key=value`，空格分隔，顺序不保证，上位机应按 key 解析。

## 3. 上位机 → 设备

| 命令 | 参数 | 说明 |
| --- | --- | --- |
| `help` | — | 列出全部命令 |
| `status` | — | 返回当前完整状态 |
| `temp` | — | 读一次温度 |
| `speed <0-100>` | 占空比 | 手动调速，自动切到 MANUAL 模式 |
| `mode <auto\|manual\|off>` | 模式 | 切换工作模式 |
| `target <℃>` | 目标温度 | 自动模式阈值，范围 15–35 |
| `save` | — | 参数写入 Flash |
| `reset` | — | 恢复出厂参数（不自动保存） |
| `evt <on\|off>` | — | 开关周期事件上报 |
| `sense <voice\|gesture> <on\|off>` | — | 单独开关语音/手势输入（调试时排除误触发） |
| `raw <0-100>` | 占空比 | 绕过温控直接测试 PWM（调试用） |

示例：

```
> speed 60
OK speed=60 mode=manual
> target 24
OK target=24.0
> foo
ERR 1 unknown_cmd
```

## 4. 错误码

| code | 含义 |
| --- | --- |
| 1 | 未知命令 |
| 2 | 参数缺失或越界 |
| 3 | 当前模式下命令不可用（如 OFF 模式下调速） |
| 4 | 传感器故障，无法执行 |
| 5 | 堵转保护中，拒绝启动 |
| 6 | 参数保存失败（Flash 写入错误） |

## 5. 约定

- 命令大小写不敏感，参数中不出现空格
- 设备逐行处理，主循环内不做阻塞等待；未识别命令不崩溃
- 上位机应容忍乱码/心跳丢失，超时 2 s 重连串口
- 保留以 `@` 开头的行作为 v2 JSON 帧（`@{"cmd":"set_speed","v":60}`），v1 设备收到应回 `ERR 1 unknown_cmd` 而不是崩溃
