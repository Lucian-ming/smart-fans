> 本节完成度：**部分**。设计侧核对（BOM、封装、引脚序、模块尺寸）已完成；**实物电参数测量与照片尚未完成**，需按 2.5 补做。

## 2.1 测试目的与项目

元器件测试分四类：

| 类别 | 目的 | 手段 |
|---|---|---|
| A 到货核对 | 型号、封装、数量、极性、丝印与 BOM 一致 | 目视 + 放大镜 + 立创订单/规格书比对 |
| B 电参数 | 阻值、容值、二极管压降、三极管 hFE、稳压输出 | 万用表 / 可调电源 / 示波器 |
| C 模块功能 | 模块能否单独工作、地址/针序是否正确 | 最小系统 + 串口/逻辑分析仪 |
| D 装配适配 | 模块外形、针距、排距、安装孔与 PCB 是否匹配 | 卡尺 + PCB 实物比对 |

## 2.4 与设计相关的"测试结论"（可直接写）

1. **LDO 选型**：AMS1117-3.3 属老式低压差器件，稳定性依赖输出电容 ESR；最终改用 TLV1117LV33（低压差、原厂稳定性要求明确），PCB 与 ERC/DRC 均按后者复核。
2. **I2C 上拉**：主板 4.7 kΩ，模块自带 4.7 kΩ 时并联为 2.35 kΩ；按条件仿真，50 pF 总线电容下上升时间 66–199 ns，均满足快速模式 300 ns；800 pF 时 4.7 kΩ 超标（见 3-2 节）。
3. **蜂鸣器**：有源蜂鸣器为感性负载，必须并 1N4148W 续流；RevA 仿真中无二极管时反峰达 782.9 V，加钳位后 5.75 V（历史数据，仅说明必要性）。
4. **电解电容**：220 µF/16V 选 Rubycon ZLH，105℃/100 kHz 下纹波电流 540 mA rms，满足 25 kHz PWM 下的母线纹波需求（按手册，未实测温升）。

## 2.6 写作提示

- 第 2 节不要写成"元件清单复述"，重点是**判据 + 异常处理 + 与设计的关联**。
- 没有实测数据时，写"测试方案与判据已制定，实测受仪器条件限制尚未完成"，比编造数字安全得多。
- 若只做了部分实测，就按"已测/未测"分两栏写，别用"全部合格"。
