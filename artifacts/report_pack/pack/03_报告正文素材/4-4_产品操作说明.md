## 4.4.1 面板与接口

**图 6 前面板开孔布置** 为面板示意（沿 25° 斜面展开，单位 mm）。从上到下、从左到右：

| 位置 | 器件 | 功能 |
|---|---|---|
| 左上 φ10 | PAJ7620U2 | 手势感应窗口（正对感应区挥手） |
| 中上 φ7 ×2 | KEY1 / KEY2 | 电源启停 / 摇头与模式 |
| 右上 φ9 | EC11 编码器 | 旋转调速（每格 10%），**无按压** |
| 最右 φ2.5 | 麦克风 | 语音拾音孔 |
| 右下 28×16.5 | 0.96″ OLED | 状态显示 |
| 右侧腔体 | MG90S | 带动机头扫风 |
| 顶部 | 130 电机 + 风叶 | 出风 |

接口区（板边）：Phoenix 5.08 mm 2P 为 **5 V 电源输入**；XH-2.5 为电机与喇叭；三只跳帽 JP_ASR / JP_ASR_TX / JP_ASR_RX 控制语音模块；JP_USB 隔离蓝板 5 V。

## 4.4.2 上电与开机

1. 确认电源是 **5 V/2 A**（4.75–5.25 V），**严禁接 12 V**；插头极性内正外负。
2. 确认 JP_USB 已插上（否则蓝板无供电）；若要用 USB 给蓝板烧录/调试，**必须先拔掉 JP_USB 并断开 5 V 输入**。
3. 上电后 OLED 点亮，显示温度、湿度、档位、模式；PC13 心跳灯 0.5 s 闪。
4. 默认进入 **MANUAL 手动模式、40% 档**、摇头关闭。
5. 待机 10 s 后 OLED 熄屏；任意按键、转编码器、说话或挥手都会立即点亮。

## 4.4.6 显示内容

OLED 一屏显示：

```
┌────────────────────────┐
│ 26.4C  58%RH           │  温度 / 湿度
│ MODE: MANUAL           │  模式（MANUAL / AUTO / OFF）
│ SPEED: 50%  [|||||   ] │  目标档位与条形图
│ SWING: ON   LV3        │  摇头状态与档位
│ TEMP: 26.4C            │  自动模式下的判定温度
└────────────────────────┘
```

待机时熄屏；故障或异常时显示 `FAULT` 提示（如传感器失联）。

## 4.4.7 安全与注意事项

1. **只接 5 V**：板上丝印 "5V prototype"，接 12 V 会烧 LDO、语音模块与电机驱动。
2. **插拔模块必须断电**：跳帽不隔离 GPIO，带电插拔可能损坏 MCU 引脚。
3. **USB 与外部 5 V 不能同时供**：插 USB 前拔 JP_USB、断外部电源。
4. **喇叭是 BTL 输出**：SPK1 两端都不可接地，否则烧功放。
5. **舵机与电机不要堵转**：堵转电流大，长时间会触发热保护或烧保险。
6. **连续舵机可能绞线**：长时间单向扫风时注意线缆，必要时限制运行时间。
7. **DHT11 在机内**：读数受功率器件发热影响，自动模式的温度会略高于环境温度。

## 4.4.8 常见"用户级"问题

| 现象 | 处理 |
|---|---|
| 按电源键没反应 | 查 5 V 输入、JP_USB 是否插好、保险是否熔断 |
| 屏幕不亮但风扇转 | 查 OLED 针序、I2C 上拉；断电重插 |
| 说话没反应 | 先说唤醒词；查三只语音跳帽；环境噪声大时靠近些 |
| 手势不灵 | 手离窗口 5–15 cm，动作慢一点，避免强光直射 |
| 摇头不动 | 查 SERVO1 是否插反（棕/黑 GND、红 5V、橙 PWM）、舵机是否卡住 |
| 自动模式温度不准 | DHT11 在机内，属已知局限；可切手动 |

## 4.4.10 本节写作提示

- 操作说明要写成"给用户看"的语气：先做什么、再做什么、看到什么算成功。
- 表格比大段文字好读；每个操作都写"反馈"，用户才知道有没有生效。
- 安全注意事项单独成段，这是产品文档的必备项。
