# 4-5 相关芯片介绍及典型应用

> 对应模板：**四、焊装、测试分析及产品操作说明 → 5、相关芯片介绍及典型应用图**
> 写法建议：每个器件 150–250 字 + 一张典型应用图。下面的 ASCII 图可直接照着用 Visio/立创 EDA/画图重绘，也可以截图数据手册的典型电路（注明出处）。

## 4.5.1 STM32F103C8T6（主控）

- **厂商/内核**：ST，ARM Cortex-M3，72 MHz，64 KB Flash，20 KB SRAM，LQFP48。
- **关键外设**：3 个通用定时器（TIM2/3/4）、2 个 SPI、2 个 I2C、3 个 USART、2 个 12 位 ADC、SWD 调试。
- **供电**：2.0–3.6 V，本机 3.3 V；VBAT 可接纽扣电池（本机未用）。
- **本项目用法**：TIM2_CH1 出 25 kHz 电机 PWM，TIM3 做编码器正交解码，TIM4_CH3 出 50 Hz 舵机 PWM，I2C1 挂 OLED 与手势，USART2 接语音，USART1 做调试 CLI。
- **典型应用（最小系统）**：

```
        3.3V ──┬── VDD(×2) ── 100nF ── GND
               ├── VDDA ── 100nF+10µF ── GND
               ├── BOOT0 ── 10kΩ ── GND（运行模式）
               ├── NRST ── 10kΩ ── 3.3V（另并 100nF 到 GND）
               └── SWDIO/SWCLK ── 调试排针
        8MHz 晶振 ── 两个 20pF ── GND（本机用蓝板板载晶振）
```

## 4.5.2 AMS1117-3.3 / TLV1117LV33（3.3 V 稳压）

- **类型**：低压差线性稳压器（LDO），固定 3.3 V 输出。
- **AMS1117-3.3**：1 A，压差约 1.1 V @1 A，SOT-223；老器件，稳定性依赖输出电容 ESR。
- **TLV1117LV33**：1 A，压差约 0.45 V @1 A（低压差），静态电流更低；本机实装型号。
- **引脚**（SOT-223）：1=GND，2=VOUT，3=VIN，Tab=VOUT。
- **本项目用法**：5 V → 3.3 V，供 OLED/手势/DHT11/EC11/TB6612 的 VCC，总电流约 92 mA 峰值。
- **典型应用**：

```
  5V ──┬── 10µF ── GND
       └── VIN [U3] VOUT ──┬── 10µF ── GND
                 GND       ├── 100nF ── GND
                           └── 3.3V 负载
  注：输出电容 10µF 以上，ESR 不宜过低（AMS1117 需 ≥0.1Ω 量级）
```

## 4.5.3 TB6612FNG（双 H 桥电机驱动）

- **厂商/参数**：Toshiba，双通道 H 桥，单通道连续 1.2 A、峰值 3.2 A，VM 2.5–13.5 V，VCC 2.7–5.5 V，PWM 频率可达 100 kHz。
- **引脚要点**：VM（电机电源）、VCC（逻辑电源）、GND、STBY（使能，低=待机）、AIN1/AIN2/BIN1/BIN2（方向）、PWMA/PWMB（调速）、AO1/AO2/BO1/BO2（电机）。
- **真值表**（A 通道）：AIN1=1/AIN2=0 正转；0/1 反转；0/0 刹车（短路制动）；1/1 停止（高阻）。
- **本项目用法**：只用 A 通道驱动 130 电机，PWMA=25 kHz，STBY 由 PB0 控制并 10 kΩ 下拉，保证上电默认关断。
- **典型应用**：

```
  VM(5V) ──┬── 100µF ── GND
           └── TB6612 VM
  3.3V ── VCC      AO1 ──┬── 电机 ──┬── AO2
  PA0  ── PWMA            └─ 100nF ──┘（可选，抑制换向噪声）
  PA1  ── AIN1     STBY ── PB0（10kΩ 下拉）
  PA5  ── AIN2     GND ── 系统地
```

## 4.5.4 AO4409（P 沟道 MOSFET，防反接）

- **参数**：−30 V，−12 A（Tc=25℃ 条件），Rds(on) ≤12 mΩ @VGS=−4.5 V，SOP-8。
- **接法**：源极接输入正极，漏极接负载正极，栅极经 10 kΩ 下拉到地；体二极管方向与正常电流一致。
- **原理**：正接时 VGS≈−5 V 导通，压降仅几十 mV；反接时 VGS≈0 截止，负载断电。
- **典型应用**：

```
  VIN+ ──┬── S [Q_PWR] D ── VOUT+
         │        │ G
         │        └── 10kΩ ── GND
  VIN- ────────────────────── GND（共地）
  注：栅极可并联 12V 稳压管做栅压钳位（本机 5V 输入未加）
```

## 4.5.5 2N3904 + 1N4148W（蜂鸣器驱动）

- **2N3904**：NPN 小信号管，Ic 200 mA，hFE 100–300，SOT-23。
- **1N4148W**：高速开关二极管，75 V/300 mA，SOD-123。
- **接法**：基极经 1 kΩ 接 MCU，发射极接地，集电极接蜂鸣器负极；蜂鸣器正极接 5 V；**二极管反并在蜂鸣器两端**（阴极接 5 V）。
- **典型应用**：

```
  5V ──┬── BZ1(+) ── BZ1(−) ──┬── Q1(C)
       └── 1N4148W(阴极)      │
           1N4148W(阳极) ─────┘
  PB15 ── 1kΩ ── Q1(B)    Q1(E) ── GND
```

## 4.5.6 PAJ7620U2（手势识别）

- **厂商/接口**：PixArt，I2C（地址 0x73），3.3 V 供电，内置 9 种手势识别引擎，INT 引脚可中断。
- **识别手势**：上、下、左、右、前、后、顺时针、逆时针、挥手。
- **本项目用法**：模块 5P（3V3/GND/SCL/SDA/INT），INT 接 PA4 下降沿中断，30 ms 轮询 + 200 ms 防重复。
- **典型应用**：

```
  3.3V ──┬── 100nF ── GND
         └── PAJ7620 VCC
  PB6 ── SCL ── 4.7kΩ ── 3.3V
  PB7 ── SDA ── 4.7kΩ ── 3.3V
  PA4 ── INT（内部上拉，下降沿有效）
```

## 4.5.7 DHT11（温湿度）

- **参数**：温度 0–50℃ ±2℃，湿度 20–90%RH ±5%，单总线，3.3–5.5 V，采样周期 ≥1 s。
- **时序**：主机拉低 ≥18 ms 起始 → 释放 → 从机回 80 µs 低 + 80 µs 高 → 40 bit 数据（湿度整数/小数、温度整数/小数、校验和）。
- **本项目用法**：PB9 + 4.7 kΩ 上拉，每 2 s 读一次；读失败保留上次值并置错误标志。
- **典型应用**：

```
  3.3V ── 4.7kΩ ──┬── DATA ── PB9
                   └── DHT11 DATA
  DHT11 VCC ── 3.3V（或 5V，模块自带稳压时按模块标注）
  DHT11 GND ── GND
  注：数据线长度 <1 m，远离电机 PWM
```

## 4.5.8 ASR-PRO（离线语音模块）

- **形态**：30×28×2.9 mm 双排 7P/8P 模块（本项目按 8P 设计，实物针数需核对），内置语音识别 + 语音合成 + 功放。
- **接口**：UART1 115200（TX/RX）、5 V 供电、喇叭输出（BTL）、麦克风输入。
- **开发**：天问 Block 图形化配置唤醒词与命令词，编译后经串口烧录。
- **本项目用法**：识别 20+ 命令词，向 STM32 发 `FON/FOFF/F+/F−/...`，接收 ACK 后播报；同时驱动两块 MAX7219 点阵做表情。
- **典型应用**：

```
  5V ──┬── 100µF ── GND
       └── ASR VCC
  ASR TX ── PA3（USART2_RX）
  ASR RX ── PA2（USART2_TX）
  SPK+ / SPK− ── 8Ω 2W 喇叭（BTL，两端都不可接地）
  MIC+ / MIC− ── 驻极体咪头
```

## 4.5.9 MAX7219（8×8 点阵驱动）

- **参数**：SPI 三线（DIN/CLK/CS），单颗驱动 8×8 LED，级联可扩展；5 V 供电，段电流由外接电阻设定。
- **本项目用法**：两块级联做"眼睛"，50 ms 刷新，8 种表情；数据由 ASR-PRO 侧产生（不占 STM32 资源）。
- **典型应用**：

```
  ASR P1-7(5V) ── VCC（严禁 3V3）
  ASR P1-8     ── GND
  PA0 ── CLK，PA5 ── DIN，PA6 ── CS（第一块）
  第一块 DOUT ── 第二块 DIN（DIN/CLK/CS 并联）
  两块 VCC/GND 并联，各并 100nF
```

## 4.5.10 MG90S（360° 连续旋转舵机）

- **参数**：工作电压 4.8–6 V，堵转扭矩约 1.8 kg·cm，金属齿轮，PWM 50 Hz。
- **控制**：1500 µs 停转，1300 µs 反转，1700 µs 正转（不同批次略有差异）。
- **本项目用法**：TIM4_CH3 出 50 Hz，5 档半周期定时换向，回中软刹车 + kickstart。
- **典型应用**：

```
  5V ──┬── 100µF ── GND
       └── SERVO VCC（红）
  GND ── SERVO GND（棕/黑）
  PB8 ── SERVO PWM（橙/黄）
```
