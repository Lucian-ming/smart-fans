# 1 自主实习题目、任务要求、技术指标

> 本节完成度：**可写**（指标状态需按表如实标注）

## 1.1 自主实习题目

**基于离线语音与手势交互的温控智能风扇设计**

设计一台立式桌面智能风扇：以 STM32F103C8T6 为主控，支持按键、旋转编码器、手势、离线语音四种交互方式；根据环境温度自动调速；舵机带动机头往复扫风；OLED 显示温度、档位、模式与状态；整机由 3D 打印外壳承载，单 5V 供电。

## 1.2 任务要求

1. 完成需求分析、方案选型与系统框图，给出供电、主控、执行、交互、显示的完整方案。
2. 完成原理图设计与 PCB 设计，输出 Gerber、BOM、坐标文件，板级检查（ERC/DRC/制造审计）通过。
3. 完成嵌入式固件：状态机、调速、温控、扫风、显示、按键/编码器/手势/语音驱动与调试命令。
4. 完成外壳结构设计与 3D 打印文件，控制材料体积在打印券限额内。
5. 完成元器件采购、焊接、分块上电与整机联调（受条件限制，实物环节尚未完成，见第 4 节）。
6. 撰写总结报告，给出测试数据、问题分析与改进方向。

## 1.4 方案调整说明（开题 → 实现）

**表 1-2 方案调整对照**

| 项目 | 开题方案 | 最终方案 | 调整原因 |
|---|---|---|---|
| 架构 | 手势遥控端 + 风扇执行端，双 ESP32-C3，ESP-NOW | 单块 STM32F103 主板，手势传感器上板 | 单板即可覆盖语音+手势+按键三类交互；避免无线配对、重发、去重带来的调试风险与工期 |
| 风扇 | 12025 4-Pin PWM 风扇（25 kHz + FG 测速） | 130 直流电机 + TB6612FNG | 手头器件与成本；4-Pin 风扇的 FG 堵转检测需额外捕获与判据 |
| 测温 | DS18B20 | DHT11（温度+湿度） | 器件到货情况；单总线协议相近 |
| 扫风 | SG90 位置舵机 0–90° | MG90S 360° 连续舵机 + 定时换向 | 手头舵机为连续旋转型；用时间近似扇面并加回中软刹车 |
| 电源 | 12V 输入 + XL1509 降压 + AMS1117 | 单 5V 输入 + AO4409 防反接 + AMS1117/TLV1117 | 去掉一级降压，减少失效点；风扇、舵机、语音模块本身均为 5V 器件 |
| 交互 | 语音 + 无线手势 + 按键 | 语音 + 板载手势 + 按键 + 编码器 | 见架构行 |

> 这段建议配一张"方案演进"小表或时间线，老师通常很看重"为什么改"。

## 1.6 本节可直接用的开头段

> 本次自主实习的题目是"基于离线语音与手势交互的温控智能风扇设计"。选择该题目的出发点是：风扇是典型的小型机电一体化产品，既包含电源、驱动、传感、人机交互等硬件内容，又包含状态机、闭环控制、通信协议等软件内容，适合作为电子工艺实习的综合载体。设计目标是做出"能演示、能拆解、能讲清原理"的桌面样机，因此在方案上优先保证单板可靠性与可调试性，最终形成以 STM32F103 为核心、单 5V 供电、四种交互方式并存的整机方案。
