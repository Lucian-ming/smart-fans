# 3-1 工作原理

> 对应模板：**三、项目设计内容 → 1、工作原理**（约 1200–1600 字，配图 1、图 2、图 3）

## 3.1 系统组成

整机由六部分组成（对应图 1 系统总体框图）：

1. **电源与保护**：单 5 V 适配器输入 → 3 A 快断保险 F1 → AO4409 P-MOS 防反接 → +5 V 动力轨；再经 AMS1117-3.3（实装 TLV1117LV33）得到 +3.3 V 逻辑轨。
2. **主控**：STM32F103C8T6 最小系统板（72 MHz Cortex-M3、64 KB Flash、20 KB SRAM），通过双排 20P 母座插装在主板上。
3. **执行机构**：TB6612FNG 驱动 130 直流电机（风叶）；MG90S 360° 连续旋转舵机带动机头左右扫风。
4. **感知**：DHT11 测温湿度、PAJ7620U2 手势识别、EC11 增量编码器、两个轻触按键。
5. **人机交互**：0.96″ 128×64 OLED（I2C）、有源蜂鸣器、ASR-PRO 离线语音模块 + 麦克风 + 8 Ω/2 W 喇叭、MAX7219 双 8×8 点阵"眼睛"。
6. **结构与供电接口**：3D 打印下壳 + 可拆盖 + 风扇/舵机支架；Phoenix 5.08 mm 2P 输入端子、XH-2.5 电机/喇叭座、跳帽隔离。

## 3.2 供电链路

**图 2 电源链路与保护拓扑** 给出完整路径：

```
5V/2A 适配器 → J_PWR(Phoenix 1729128) → F1(0451003.MRL, 3A) → Q_PWR(AO4409, P-MOS 防反接) → +5V 动力轨
                                                                                  ├─ TB6612 VM（电机）
                                                                                  ├─ SERVO1（舵机 5V）
                                                                                  ├─ ASR-PRO（语音模块）
                                                                                  ├─ BZ1 / 点阵
                                                                                  ├─ JP_USB → 蓝板 5V → 板载 LDO → 3.3V 逻辑轨
                                                                                  └─ U3(AMS1117-3.3) → +3.3V 逻辑轨
```

要点：

- **为什么用 P-MOS 防反接**：AO4409 是 −30 V/… 的 P 沟道 MOSFET，栅极经电阻拉到地、源极接输入，正常极性时 VGS = −5 V（≤12 mΩ），压降只有几十毫伏；反接时栅源电压反向、器件截止，比串联肖特基二极管（0.3–0.5 V 压降、2 A 时 0.6–1 W 发热）效率高得多。
- **为什么去掉 12 V**：早期方案是 12 V 输入 + XL1509 降压到 5 V，但风扇、舵机、语音模块本身都是 5 V 器件，多一级开关电源只增加失效点与纹波，最终改为单 5 V 输入。
- **两套电源域**：+5 V 动力轨只给电机、舵机、语音、蜂鸣器、点阵；+3.3 V 逻辑轨给 OLED、手势、DHT11、EC11、TB6612 的 VCC。**全系统共地**，电机大电流不流经逻辑地。
- **跳帽隔离**：JP_USB 隔开母板 5 V 与蓝板 5 V（插 USB 调试时必须先拔掉，否则两路 5 V 顶牛）；JP_ASR / JP_ASR_TX / JP_ASR_RX 三只跳帽用于隔离语音模块的供电与串口，便于分段排查。
- **注意**：跳帽只隔离电源/信号通路，**不隔离 GPIO**，插拔模块前必须断电。

## 3.3 主控资源分配

STM32F103C8T6 的定时器与外设分配做到"零冲突"（对应表 3-1）：

**表 3-1 引脚与外设分配**

| 引脚 | 网络 | 外设/模式 | 说明 |
|---|---|---|---|
| PA0 | TB_PWMA | TIM2_CH1 PWM 25 kHz | 电机调速，占空比 0–100% |
| PA1 | TB_AIN1 | GPIO 推挽 | 方向 1 |
| PA5 | TB_AIN2 | GPIO 推挽 | 方向 2 |
| PB0 | TB_STBY | GPIO 推挽（10 kΩ 下拉） | 驱动使能，默认关断 |
| PB8 | SERVO_PWM | TIM4_CH3 PWM 50 Hz | 舵机 0.5–2.5 ms 脉宽 |
| PB6/PB7 | I2C1_SCL/SDA | I2C1 开漏 + 4.7 kΩ 上拉 | OLED 0x3C、PAJ7620 0x73 |
| PA4 | GEST_INT | EXTI 下降沿 | 手势中断 |
| PA6/PA7 | ENC_A/ENC_B | TIM3 编码器模式 | 硬件正交解码，不占 CPU |
| PB12 | — | 留空 | 5 脚 EC11 无按压开关，严格未启用 |
| PB13 | KEY1 | GPIO 上拉 + 消抖 | 电源启停 |
| PB14 | KEY2 | GPIO 上拉 + 消抖 | 短按摇头 / 长按切模式 |
| PB15 | BUZZER | GPIO → 2N3904 | 有源蜂鸣器，1N4148 续流 |
| PB9 | DHT11 | 单总线（4.7 kΩ 上拉） | 每 2 s 读一次 |
| PA2/PA3 | VOICE_TX/RX | USART2 115200 | 与 ASR-PRO 通信 |
| PA9/PA10 | DBG_TX/RX | USART1 115200 | 调试 CLI |
| PC13 | LED | GPIO | 心跳/状态指示 |
| — | SWDIO/SWCLK | SWD | 烧录与在线调试 |

资源分配的两个关键点：

1. **PWM 用 TIM2_CH1、舵机用 TIM4_CH3**，互不抢定时器；编码器用 TIM3 的硬件编码器模式，正交解码在硬件完成，软件只读计数。
2. **I2C1 同时挂 OLED 与手势传感器**，地址不冲突（0x3C / 0x73）；两者都支持热插拔重试（OLED 500 ms、手势 1 s 周期重初始化），接触不良时不至于死机。

## 3.4 控制原理

### 3.4.1 电机调速

TB6612FNG 是双 H 桥，单通道连续电流 1.2 A、峰值 3.2 A。本项目只用 A 通道：PWM 加在 PWMA 上（25 kHz，高于人耳可听范围，避免电机啸叫），AIN1/AIN2 定方向，STBY 拉高使能。转速开环，占空比即"档位"，10% 为一步。选择 25 kHz 而不是 1 kHz，是因为 1 kHz 落在人耳敏感区，且电流纹波大、转矩脉动明显。

### 3.4.2 温度自动调速

DHT11 每 2 s 采样一次，状态机在 AUTO_TEMP 状态下按 5 段曲线设定目标占空比：

| 温度 | 目标占空比 |
|---|---|
| < 24 ℃ | 0%（停转） |
| 24–26 ℃ | 30% |
| 26–28 ℃ | 50% |
| 28–30 ℃ | 75% |
| > 30 ℃ | 100% |

> 早期需求写的是"26 ℃ 起转 25%、32 ℃ 到 100%、0.5 ℃ 回差"，实现改为 5 段固定档位，理由是 DHT11 分辨率只有 1 ℃，0.5 ℃ 回差没有意义；5 段曲线也更符合"体感"而非"精确控温"的产品定位。报告里请统一用 24/26/28/30 这套数字。

手动的优先级高于自动：在 AUTO_TEMP 下只要转动编码器或说"风速加/减"，立即强制回到 MANUAL_RUN，避免"刚调好又被温控改掉"。

### 3.4.3 扫风

MG90S 是 360° 连续旋转舵机，PWM 脉宽决定**转速与方向**而不是角度：约 1500 µs 停转，>1500 µs 正转、<1500 µs 反转，偏离越大越快。固件用"单向运行固定时间再反向"来近似 90° 扇面：

- 档位 1–5 对应单向半周期 2400 / 2200 / 2000 / 1800 / 1500 ms；
- 换向前先给 120 ms 回中（1500 µs）做软刹车，减少齿轮冲击；
- 启动瞬间叠加 100 ms、+14 µs 的 kickstart，克服静摩擦死区；
- 出厂前可用 `servo_cal` 命令做 ±200 µs 死区校准。

局限必须写清：连续舵机没有位置反馈，角度是"时间×转速"的近似，长时间运行会漂移；也没有限位与滑环，**连续单向旋转可能绞线**。

### 3.4.4 状态机

**图 3 主状态机** 是软件的核心：POWER_OFF（待机，输出 0，10 s 后熄屏）、MANUAL_RUN（手动，40% 起调）、AUTO_TEMP（按温度 5 段）、TEST_MODE（CLI 单模块自检）。转移条件：

- POWER_OFF ↔ MANUAL_RUN：KEY1、语音 FON/FOFF、手势 WAVE；
- MANUAL_RUN ↔ AUTO_TEMP：KEY2 长按、语音 FMODE/FAUTO/FMANU；手动调速强制回 MANUAL；
- 任意状态 EMERGENCY_STOP 或 target=0 → POWER_OFF；
- CLI `test ...` 进出 TEST_MODE。

状态机与驱动分离：`fan_fsm.c` 只做"事件 → 目标值"的纯逻辑（可在 PC 上跑单元测试，46 个断言全过），`motor.c`/`servo.c` 只执行，`main.c` 负责把按键、编码器、语音、手势转成事件。

## 3.5 交互与显示

- **按键**：KEY1 短按/长按都是电源启停（40 ms 蜂鸣反馈）；KEY2 短按切摇头、长按切模式（双响）。非阻塞消抖 + 8 深度事件队列，主循环不因按键阻塞。
- **编码器**：TIM3 硬件正交解码，每格 ±10%，范围 0–100%；转到 0 即进待机。
- **手势**（PAJ7620，200 ms 防重复）：上/下 +/−10%，前/后 50%/0%，右/左 开/关摇头，顺时针/逆时针切模式，挥手电源开关。
- **语音**（ASR-PRO，UART 115200，双唤醒词"风扇风扇/小风扇"）：20+ 命令词映射到 FON/FOFF/F+/F−/FMAX/FMOD/FMIN/FMODE/FAUTO/FMANU/SWON/SWOFF/SW+/SW−/FSLEEP/QTEMP/QSTAT 等命令字；STM32 回 ACK（如 "Fyes"/"Foff"），语音模块据此播报确认。语音模块同时驱动两块 MAX7219 点阵做 8 种"眼睛"表情（眨眼、笑眼、安睡、张望、惊讶、爱心、眩晕等），提升交互趣味性。
- **OLED**：128×64，I2C 0x3C；主循环每 150 ms 刷新一次，显示温度/湿度、目标与当前占空比、模式（手动/自动）、摇头状态、Wi-Fi 图标位置留空（v1 不联网）。待机 10 s 熄屏，任意交互立即点亮。

## 3.6 软件结构

```
firmware/src/
├── main.c            主循环：CLI→按键→编码器→语音→手势→FSM→执行器→显示
├── app/
│   ├── fan_fsm.c     状态机（纯逻辑，可单测）
│   └── cli_test.c    串口 CLI（help/status/safe/test ...）
├── drivers/          button/buzzer/dht11/encoder/i2c_bus/max7219/
│                     motor/paj7620/servo/ssd1306/voice_asr
├── config/pins.h     引脚集中定义
└── hal/delay_us.c    微秒延时（DHT11/舵机时序）
```

时间基准：SysTick 1 ms；主循环节拍 20 ms；DHT11 2 s；OLED 150 ms；手势轮询 30 ms + 中断；心跳 LED 0.5 s。整机固件 35,948 B，占 Flash 54.8%，SRAM 17.5%，留有余量。
