# 4-3 调试方法

> 对应模板：**四、焊装、测试分析及产品操作说明 → 3、调试方法**（约 900–1300 字）

## 4.3.1 总体策略：分层 + 分段 + 可观测

调试遵循三条原则：

1. **分层**：电源 → 最小系统 → 单模块 → 双模块 → 整机，任何一层不通，不往上走。
2. **分段上电**：用跳帽/排母把系统切成"电源区、主控区、执行区、交互区、语音区"，逐段限流上电。
3. **可观测**：固件内置串口 CLI 与心跳灯，让"看不见的状态"变成"可读的字符串"。

**表 4-5 分层调试步骤**

| 层 | 目标 | 方法 | 通过标准 |
|---|---|---|---|
| L0 目视 | 无短路、无错件、无虚焊 | 放大镜 + 万用表通断 | 5 V 对地 >1 kΩ |
| L1 电源 | 5 V/3.3 V 正常 | 限流 0.1 A 上电，测电压/电流/纹波 | 4.9–5.1 V、3.25–3.35 V、纹波 <100 mV |
| L2 最小系统 | 能烧录、能跑 | SWD 连接、烧录 blink | PC13 0.5 s 闪，串口有 banner |
| L3 单模块 | 每个模块单独工作 | CLI `test <模块>` | 见 4.3.2 命令表 |
| L4 组合 | 两两组合不打架 | 如 OLED+手势同挂 I2C | 不互相复位，地址都在 |
| L5 整机 | 全功能联调 | FSM 全状态遍历 | 无死机、无异常复位 |

## 4.3.2 固件自带的调试手段

串口 USART1（115200，8N1）提供 CLI，命令如下：

**表 4-6 调试命令**

| 命令 | 作用 |
|---|---|
| `help` | 列出所有命令 |
| `status` | 打印状态机状态、目标/实际占空比、温度、湿度、模式、摇头状态 |
| `safe` | 立即停机（PWM=0、舵机回中、STBY 拉低） |
| `test led` | 心跳灯闪烁 |
| `test buz` | 蜂鸣器响一声 |
| `test key` | 打印按键事件（短按/长按） |
| `test enc` | 打印编码器计数与方向 |
| `test dht` | 读一次温湿度并打印原始字节 |
| `test i2c` | 扫描 I2C 总线，打印在线地址 |
| `test oled` | 显示测试画面（棋盘/字符） |
| `test gest` | 打印手势事件与 INT 计数 |
| `test voice` | 打印语音模块收到的命令字 |
| `test motor` | 按 10% 步进扫一遍占空比 |
| `test servo` | 正转/停/反转各 2 s |
| `servo_cal` | ±200 µs 校准舵机死区（掉电保存） |

除此之外还有两个"硬件级"观测点：PC13 心跳灯（0.5 s 闪 = 主循环活着）和蜂鸣器短鸣（事件被处理的即时反馈）。

## 4.3.3 常见故障与定位

**表 4-7 故障现象 → 原因 → 处理**

| 现象 | 可能原因 | 定位/处理 |
|---|---|---|
| 上电无反应、电流很大 | 电源短路、电解电容反接、IC 焊反 | 立即断电，测 5 V 对地电阻，目视电解白条与 IC 缺口 |
| 5 V 正常、3.3 V 为 0 | LDO 虚焊/方向错、负载短路 | 测 LDO 输入输出，断开负载再测 |
| 3.3 V 偏低（<3.1 V） | 负载过重、LDO 过热、输入不足 | 测总电流，摸 LDO 温度，查 5 V 是否跌落 |
| 烧录失败 | SWD 线序、目标未供电、BOOT 配置 | 查 SWDIO/SWCLK/GND/3.3 V，测目标电压，按复位再连 |
| 心跳灯不闪 | 程序没跑起来、时钟配置错、HardFault | 看串口 banner；用调试器看 PC；查 `Error_Handler` |
| OLED 黑屏 | 针序反、地址错、上拉缺失 | `test i2c` 看 0x3C 是否在线；万用表确认 VCC/GND |
| OLED 花屏/闪 | 电源纹波、I2C 速率过高、排线长 | 降速到 100 kHz，加 100 nF，缩短排线 |
| I2C 扫描不到手势 | 供电 3.3 V、地址 0x73、INT 未接 | 测模块 VCC，`test i2c`，查 PA4 |
| DHT11 读数全 0/全 1 | 上拉缺失、时序被中断打断、针序反 | 加 4.7 kΩ，关中断读一次，核对丝印 |
| 编码器跳数/反向 | 抖动、A/B 接反 | 加消抖，交换 A/B 或在代码里取反 |
| 电机不转 | STBY 低、VM 无电、PWM 为 0 | 测 STBY/VM，`test motor` 扫占空比 |
| 电机转但无力/发热 | 占空比低、电压跌落、堵转 | 测母线电压，查线阻（见 3.2.3） |
| 舵机抖动/不定位 | 脉宽超范围、供电不足、死区 | 1500 µs 停转验证，单独 5 V 供电，`servo_cal` |
| 语音无响应 | 跳帽未插、波特率错、唤醒词没说对 | 查三只跳帽，`test voice` 看有无命令字 |
| 喇叭无声/破音 | BTL 接法错、供电不足、音量参数 | 确认两端不接地，单独 5 V 供电 |
| 整机偶发复位 | 电机换向浪涌、地弹、5 V 跌落 | 示波器看 5 V，加 100 µF，电机线双绞 |

## 4.3.4 三个真实调试案例（建议展开写）

### 案例 1：OLED 热插拔后 I2C 死锁

**现象**：不断电插拔 OLED 后，`test i2c` 扫不到任何设备，重启才恢复。
**分析**：从机在传输中途掉电，可能把 SDA 拉低并停在"等待时钟"状态，主机再发起始条件也无效。
**处理**：在 `i2c_bus_recover()` 里发 9 个 SCL 脉冲，每发一个检查 SDA 是否释放，最后补一个 STOP；初始化时先解锁再配置。
**结果**：热插拔后可自动恢复；同时把 OLED 初始化改成 500 ms 周期重试，接触不良也不死机。

### 案例 2：编码器"转一格跳三格"

**现象**：慢转时计数正常，快转时跳数，偶尔反向。
**分析**：机械触点抖动 + 主循环轮询间隔（20 ms）漏边沿。
**处理**：改用 TIM3 硬件编码器模式（4 倍频计数），软件只读差值；对按键另做 20 ms 消抖与事件队列。
**结果**：任意速度下计数稳定，CPU 占用反而下降。

### 案例 3：舵机启动"咯噔"一下再转

**现象**：从停转切到正转时，舵机先抖一下，偶尔不启动。
**分析**：连续舵机有静摩擦死区，1500 µs 附近脉宽不足以起转；直接给大脉宽又会冲击齿轮。
**处理**：启动前 100 ms 叠加 +14 µs 的 kickstart，随后回到目标脉宽；换向前先回中 120 ms 做软刹车。
**结果**：启动平顺，换向无明显冲击；但角度仍靠时间近似，长时间运行会漂移（已知局限）。

## 4.3.5 无仪器时的替代方法

项目后期没有示波器/逻辑分析仪，采用：

- **替换法**：怀疑哪个模块就换一个已知好的；
- **对比法**：同一份固件在面包板与 PCB 上分别跑，差异即硬件问题；
- **二分法**：拔跳帽逐段隔离，缩小范围；
- **软件观测**：用 GPIO 翻转 + 万用表频率档粗测时序，用串口打点测流程耗时。
