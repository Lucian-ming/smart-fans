供电不是本次新阻断：芯片PDF页3 VCC 2.7–5.5V、VM 2.5–13.5V；页5 VIH≥0.7VCC。当前VCC3.3V合理；不要为了模块“5V”字样把VCC升5V（VIH最低3.5V不保证3.3V MCU可靠驱动）。模块OCR正文VM4.5–10V，VM5V落在范围内，但此事实不证明130电机额定电压/堵转电流。

## 3. EC11：现有单排5P与资料2P+3P候选冲突

当前[J_ENC](<D:/smart_fans/tools/build_perfect_revB_v3.py#L493-L504>)是单排5P P2.54，Y82.5、X65.92/68.46/71/73.54/76.08，顺序**GND、3V3、ENC_SW、ENC_B、ENC_A**。这是假定带独立按压输出的单排接口。

但原始OCR接口文字是`VCC()C (V) GND`及`3P0号的出口；A ... B ... C(GND)`；尺寸图再次出现`VCC 0 0 GND`和下一行3个孔。旋转OCR也读到`VCC 0 0 GND`。**支持“2针电源+另3针A/B/C公共地”，不支持现有单排5针，更没有读到SW独立输出。**“未读到SW”不等于器件物理上绝无按压开关，但当前设计不能依赖其存在。

精确风险：
1. 若实物确为2P+3P分组，现有1×5排母不能直接插入，不是只需翻转顺序。
2. C标为GND，不应当作第三路按压输出；若线束把C接ENC_SW，按键输入会常低且实际按压功能不存在/不可用。
3. A/B互换通常只改变方向，固件可修；电源/GND/公共端错接则不是固件问题。
4. OCR写额定DC5V，缺输出上拉/电路图；现用3.3V是否正常、若5V供电A/B是否上拉到5V均未证明。不要仅凭EC11系列名认定可直接接MCU。
5. 唯一较稳定尺寸24mm不能确定轴向或排针相对位置；不能拿它算任意排距。

## 4. 最小用户问题（仅两组，足以决定PCB接口）

**TB：**“请量两排针中心线间距是否15.24mm，并拍/抄元件面朝上时两列从同一端开始的8个丝印；请标出VM和PWMA所在端。”可用卡尺测两排同侧针边缘距离（等直径时等于中心距）；不是板外宽。若不量，选择线束连接而非直插，需明确授权变更装配方式。

**EC：**“你的实物是单排5针GND/+ /SW/B/A，还是2针VCC/GND加另3针A/B/C？请给正反面清晰照片或逐针抄字；旋钮能否按下、按压是否有独立SW端？如果要直插，再量孔距及两组相对位置。”若实物只有A/B/C且没有可引出的SW，需要选择取消编码器按压功能/用现有独立按键代替，而非伪造SW网络。3.3V供电可用性应以对应模块电路或低压实测确认。

## 5. 冻结条件

- TB：确认15.24排距、2.54单排pitch与顶视两列同端针序，或明确改用带线序表的线束接口。
- EC：确认实际接口分组及SW有无后更改母座；若线束方案，明确A/B/C与电源端点映射，C接地，SW功能另定。
- 本次不要求重复确认ASR；不扩展到机械外壳。没有把缺证判成必错，也没有用几何DRC通过替代模块接口匹配。
