## 1. TB6612模块

源文件：[模块使用说明PNG](<E:/桌面/原理图/9-TB6612电机驱动/电机驱动模块使用说明.png>)与[TB6612FNG芯片PDF](<E:/桌面/原理图/9-TB6612电机驱动/TB6612FNG.pdf>)。该目录完整扫描只有这两件，**没有模块PCB工程、机械尺寸图或标注排间距的独立文件**。

### 已确认的电气事实

芯片PDF第3页工作范围VCC=2.7–5.5V，VM=2.5–13.5V；绝对最大VM=15V并非建议工作电压。第5页逻辑VIH≥0.7VCC，VIL≤0.3VCC，所以3.3V MCU直接驱动时采用3.3V VCC有依据，不应为了“模块写5V”盲改成5V逻辑。第3页工作条件无PWM输出电流：VM≥4.5V时1.0A，低于4.5V时0.4A；1.2A/3.2A额定/峰值不可直接当持续设计电流。

模块说明OCR正文为VM驱动输入 **4.5–10V**、VCC逻辑2.7–5.5V，与芯片允许到13.5V不同，应优先保守遵守具体模块说明范围，仍需模块元件额定值检查。

### 针序和排距的状态

OCR原图在左列约x190–290、y1052–1352读出类似 `PWMA / AIN2 / AIN1 / STBY / BIN1 / BIN2 / PWMB / GND`。右列约x394、y1140–1360读出 `GND / AO1 / AO2 / BO2 / BO1 / GND`，二次OCR包含`VCC`，顶部VM未稳定识别。部分原字符为`PUNR`、`俪、N2`等，**这里的正常拼写只是候选解释，不能当已验证物理引脚顺序**。

当前主脚本使用两排1×8、单排P2.54，右排中心x23.12；模块两排实际孔中心距、板外框、安装方向均未从新资料取得可靠数值。图片投影和不带标尺的说明图不能证明排间距。下单若要求模块直接双排插装，仍需标尺正视照片/卡尺测距或模块PCB文件；如果无法确认，应使用明确线序的独立线束而不是假定插座间距，但这属于设计选择，当前未实施。

### 电机本体电压仍未知

该模块说明的4.5–10V是**驱动板输入能力**，不是130电机铭牌。对提供目录的图片/PDF名称扫描未发现具体电机型号或“该电机额定3–6V”的证明。不能据此直接认定单5V入口能够驱动现有电机，或者认定必须12V。若主设计选择5V入口，需要用户确认电机额定电压/启动和堵转电流；这不影响“当前TB芯片本身允许VM5V”的事实。

## 2. OLED四针电气连接——有强文字/坐标证据

源：[中景园IIC接口原理图](<E:/桌面/原理图/8-OLED显示屏/中景园电子0.96OLED显示屏原理图/中景园电子0.96OLED显示屏IIC接口原理图.pdf.pdf>)，第1页，2016-01-18 V1.0。J1为CON4。

| J1脚号 | 网络 | PDF文字框Y范围（pt，顶为0） | 引脚线Y（pt） |
|---|---|---|---|
| 1 | GND | pin1 312.386–317.293；GND 312.509–317.416 | 317.400 |
| 2 | VCC_IN | pin2 306.989–311.896；VCC_IN 306.507–311.413 | 312.000 |
| 3 | SCL | pin3 301.469–306.375；SCL 301.587–306.493 | 306.480 |
| 4 | SDA | pin4 295.949–300.855；SDA 296.067–300.973 | 300.960 |

每条矢量引脚线从x229.920至246.240，文字pin号x233.739，网络标签x252.816，次序一致。**确定原理图J1为1=GND、2=VCC_IN、3=SCL、4=SDA**，与当前主脚本J_OLED逻辑映射一致。但“从正面看左到右”的物理朝向仍须结合结构图pin1位置，不能仅由原理图纵排顺序认定装配方向。

原图写有662K为3.3V稳压、外部高于3.3V起保护、直接供3.3V不需要662K；不能据此证明用户实板已旁路LDO。现有PCB给3.3V，需确认模块修订版在3.3V输入下的实际显示可靠性。原图0x78/0x7A为带R/W位常用表示，对应7位地址0x3C/0x3D，不应直接把0x78传给要求7位地址的接口。

## 4. 旋转编码器模块——存在接口形态不一致风险

源：[旋转编码器模块使用说明](<E:/桌面/原理图/11-旋转编码器/旋转编码器模块使用说明.png>)。该目录本轮扫描只有此PNG，没有PCB文件或机械CAD。

- OCR“产品尺寸”处明确有 **24mm**，原词框约(338,2720)。其对应轴方向、另一维、轴心到排针中心距离没有足够文字/坐标证明，不能自动写成24×某值。
- 接口说明（约y2307–2390）OCR有左侧`VCC...GND`，右侧`3P信号输出口`及`A...B...C(GND)`。**候选是2pin电源+3pin信号的模块，而非当前假设的单排5pin CLK/DT/SW/+ /GND。** OCR并未可靠读到独立SW按压输出。这是需要人工/实物确认的差异，不是已确证无按压开关。
- 所以不能因为“EC11”这个编码器系列名称就认定现有J_EC11单排母座匹配此模块。必须确认实际模块接口的物理分组、排列、P间距、电源、电平和按压信号有无。
- 图片写“手工测量有误差，请以实物为准”；额定DC5V字样不能证明模块A/B输出可以安全直接接3.3V MCU，需看上拉/输出电路，建议以3.3V供电可行性或电平转换方案进一步确认。

## 给主设计的可执行结论

1. OLED J1逻辑1/GND、2/VCC、3/SCL、4/SDA可作为已确认电气依据；物理朝向另验。
2. TB模块两排间距仍未知；新资料尚不能批准直插双排封装。既有芯片24脚封装尺寸与2×8模块针脚尺寸无替代关系。
3. EC接口存在2+3pin与现有1×5pin不一致候选，应在冻结PCB前确认，而不是补一条“所有模块匹配”结论。
4. 没有现有电机额定3–6V的证据。模块VM允许5V不等于电机5V性能和堵转电流已确认。
5. 所有模糊OCR尺寸保持未知；本次未操作用户桌面窗口，也未绕过图片模型不支持的限制声称视觉检查通过。
