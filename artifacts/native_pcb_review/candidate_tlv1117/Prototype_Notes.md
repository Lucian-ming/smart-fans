# RevB 单5V / TI稳压器版：打样前限制

本文件适用于新版原生KiCad候选，不适用于已撤回的旧包。是否完成制造检查以同目录最终审核报告和哈希清单为准。

- **仅允许5V输入，绝不能接12V。** 输入为Phoenix 1729128接线端子，不是桶形插座；这是用户后来批准的单5V版本。
- U3采用TI TLV1117LV33DCYR / C15578，不能用同名其他厂家替代。新焊盘按TI DCY推荐包络；矩形角而非R0.05圆角，库存未核。
- 实心GND连接提高焊接热负荷；手焊须有合适烙铁与助焊剂，不宜反复长时间加热模块母座。
- TB6612按实测15mm排距；EC上下针组21mm且无按压SW；ASR两排25.4mm、板体30×28mm。粗测不是厂家公差认证，插装前必须确认针序与位置，不强行压入。
- OLED座中心(78.5,26.5)，顶视左至右SDA/SCL/VCC/GND，屏体需朝−Y；针排到朝ASR一侧的板边距离需小于3.5mm减安装余量。模块实体尺寸尚未完整认证，不满足此安装条件需改板，不能反插解决。
- MCU连接USB前断JP_USB，但GPIO仍可能反供；建议拔下核心板单独下载。ASR连接Type-C前断JP_ASR、JP_ASR_TX、JP_ASR_RX。不能宣称任意热插拔安全。
- 喇叭是BTL差分输出，任一端不得接地。
- 3A总保险不是TB6612电机支路限流；电机真实启动/堵转电流未知，2A系统目标未经热验证。用户没有测量仪器，建议借用设备或请有条件者检查，不直接全负载上电。
- 首次上电不接电机和舵机，使用限流电源核电源轨后逐路加模块。无仪器时不得把仿真工况当实测。
- MG90S为360°连续旋转型号，旧0–180°位置控制不能实现可靠限角扫风。固件业务、停转保护和USB供电顺序尚未完整验证。
- 教学示例引脚不能直接复制：PA2在本板用于语音串口，PB8/PB9用于舵机/DHT11，PB0是TB_STBY。详细代码对照见附带审核资料。
- 本次优先PCB，不发旧STL冒充适配当前布局。外壳/完整机电装配未签核。
- 原生工程使用KiCad 10.0.7生成及检查，不承诺可以由KiCad 8打开；Gerber/Excellon为制造交换文件。原生默认忽略项见原始ERC/DRC报告，未通过降低电气/制造间距规则取得零违规。

即使制造几何审核通过，也只适合作为少量裸板验证候选，不是免调试整机或量产认证。
