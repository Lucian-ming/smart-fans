# 开发路线图

| 阶段 | 关键交付物 | 状态 |
| --- | --- | --- |
| 1. 需求与选型 | 需求文档、器件清单、功耗预算 | 进行中 |
| 2. 原理图 | KiCad 原理图 + 网表检查通过 | 未开始 |
| 3. PCB | 布局布线完成、DRC 0 错误、Gerber 快照 | 未开始 |
| 4. 焊接 | 首板焊接完成、上电自检通过 | 未开始 |
| 5. 外壳 | CAD 完成、STEP 干涉检查通过、STL 打印试装 | 未开始 |
| 6. 固件 | 温控闭环、PWM 调速、OLED 显示、故障保护 | 未开始 |
| 7. 调试上位机（可选） | 串口命令工具、日志与曲线查看 | 未开始 |
| 8. 整机集成 | 装配、老化测试、问题清单闭环 | 未开始 |

## 阶段 1：需求与选型 ✅ 已完成（2026-11-03）

- [x] 确认风扇类型：**12 V DC 4-pin PWM**（12025），PWM 25 kHz + FG 反馈
- [x] 确认供电方案：**12 V/2 A 适配器 → 降压 5 V → LDO 3.3 V**
- [x] 确认主控：**STM32F103C8T6**（STM32Cube HAL + PlatformIO）
- [x] 确认传感器：**DS18B20**（单总线）
- [x] 确认人机交互：**旋转编码器 + 0.96" OLED（I²C）**，蜂鸣器告警
- [x] 确认语音方案：**SU-03T / ASR-PRO**（离线识别，UART2，词条在厂商平台配置）
- [x] 确认手势方案：**PAJ7620U2**（I²C1，9 种手势，INT 接 PA4）
- [x] 完成 `docs/hardware/power-budget.md` 功耗预算
- [ ] 整理数据手册到 `hardware/datasheets/`（STM32F103C8、DS18B20、OLED、风扇、SU-03T、PAJ7620）
- [ ] 收集参考例程到 `references/`（语音、手势、OLED、传感器各至少 1 份）

## 阶段 2：原理图

- [ ] 电源树：输入保护（保险丝/防反接/TVS）→ 降压 → 各电压域
- [ ] MCU 最小系统 + 下载/调试接口（USB 或排针）
- [ ] 风扇驱动（MOSFET 低边或专用驱动 IC，含续流二极管/RC 缓冲）
- [ ] 传感器接口（上拉、滤波、去耦）
- [ ] 接口保护（ESD、限流）
- [ ] 原理图 ERC 0 错误，关键网络命名清晰
- [ ] 导出 `docs/hardware/pinmap.md`

## 阶段 3：PCB

- [ ] 板框、安装孔、接插件位置与外壳/风扇对齐
- [ ] 功率回路加宽铜皮，大电流路径短而粗
- [ ] 地平面完整，模拟/数字分区
- [ ] DRC 0 错误，丝印可读（含版本号、朝向标记、极性）
- [ ] 3D 预览检查器件干涉
- [ ] 导出 Gerber + BOM + 坐标文件，存入 `hardware/fabrication/` 快照目录

## 阶段 4：焊接

- [ ] 物料齐套核对（数量、封装、极性）
- [ ] 按"先矮后高、先小后大、先贴片后插件"顺序焊接
- [ ] 每完成一个功能块，先测关键点电压再继续
- [ ] 上电前测输入阻抗，避免短路
- [ ] 记录首板问题到 `docs/logs/`

## 阶段 5：外壳

- [ ] 关键尺寸确认：PCB 外形、安装孔、接插件开口、风扇孔位、进/出风面积
- [ ] 打印定位柱/卡扣等关键件做 1:1 试配合
- [ ] 整壳打印 + 试装，检查走线与螺丝空间
- [ ] 导出 STEP 用于装配图，STL 用于打印

## 阶段 6：固件

- [ ] 最小闭环：读温度 → 算目标转速 → 输出 PWM → 读回转速（FG）
- [ ] PWM 电平适配：确认 4-pin 风扇 PWM 输入是否为 5 V 逻辑，必要时反相
- [ ] 状态机：待机 / 手动 / 自动 / 故障
- [ ] OLED 显示：温度、档位、模式、告警
- [ ] 编码器调速 + 按键切换模式，含消抖
- [ ] 参数持久化（Flash 模拟 EEPROM），掉电恢复
- [ ] 保护逻辑：堵转检测、过温降速、启动失败重试、传感器失效兜底
- [ ] 串口调试命令与日志分级

## 阶段 7：调试上位机（可选，v1 非必需）

- [ ] 串口命令工具（Python + pyserial），支持脚本化批量测试
- [ ] 温度/转速曲线查看，用于调温控参数
- [ ] 协议见 `shared/protocol/`（v1 为文本命令，v2 若联网再扩展）

## 阶段 8：整机集成

- [ ] 装配流程文档化（螺丝规格、扭力、走线）
- [ ] 连续运行老化测试（建议 ≥ 8 小时）
- [ ] 噪声与风量主观/客观记录
- [ ] 问题清单归档，决定是否迭代 revB
