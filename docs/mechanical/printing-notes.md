# 3D 打印与外协说明

> 适用：桌面 FDM 打印（PLA/PETG）。若用光敏树脂或外协 CNC/注塑，参数需另定。

## 1. 流程

```
CAD 建模 (mechanical/cad/)
   → 导出 STEP（整机装配 / 干涉检查）→ mechanical/step/
   → 导出 STL（单件打印）→ mechanical/stl/print/
   → 切片（记录参数）→ mechanical/print-profiles/
   → 打印 → 试装 → 修正
```

**先打关键件**：PCB 定位柱、风扇安装耳、接插件开口。这几个件 1:1 试装通过，再打整壳，能省大量耗材与时间。

## 2. 推荐打印参数（PLA，0.4 mm 喷嘴）

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| 层高 | 0.2 mm（外观面 0.12 mm） | 强度与时间平衡 |
| 墙数 | 3 层 | 结构件建议 3–4 层 |
| 顶/底 | 4 / 3 层 | |
| 填充 | 15%（外观件）/ 30%（受力件） | 蜂窝或 gyroid |
| 温度 | 喷嘴 210 ℃ / 热床 60 ℃ | PETG：240/80 |
| 速度 | 外壁 40 mm/s，填充 80 mm/s | |
| 冷却 | 100%（PLA） | PETG 适当降低 |
| 支撑 | 仅在悬垂 > 55° 处，树状支撑优先 | 支撑面尽量朝内 |

## 3. 公差与配合

FDM 热收缩与挤出膨胀会让孔变小、轴变大，按经验预留：

| 配合 | 预留量 | 示例 |
| --- | --- | --- |
| 螺丝过孔（M3） | 孔径 3.4 mm | 自攻螺丝可 2.8–3.0 mm |
| 定位柱插入孔 | 单边 +0.2 mm | φ4 柱 → φ4.4 孔 |
| 卡扣/插接 | 单边 +0.15～0.25 mm | 需试打验证 |
| 风扇框与壳体 | 单边 +0.3 mm | 避免挤压变形 |
| 滑动配合 | 单边 +0.3 mm | 打印方向影响大 |

## 4. 结构设计要点

- **进风/出风面积**：有效开孔面积 ≥ 风扇扫掠面积的 70%，过低会显著增加噪声与降低风量。
- **风道**：风扇到出风口的距离尽量短，避免直角急转；出风口加导流圆角。
- **减振**：风扇与壳体之间加硅胶垫或软 TPU 垫圈，避免壳体共振。
- **走线**：预留 ≥ 4 mm 线槽与扎带位，避免线材被夹。
- **装配顺序**：设计时就确定"先装什么、后装什么"，避免最后一步无法拧螺丝。
- **PCB 固定**：定位柱 + 1–2 颗螺丝即可，避免全螺柱导致装配应力。
- **散热**：若降压/MOSFET 发热明显，壳体对应位置开百叶窗或贴导热垫到外壳。

## 6. 常见问题

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 螺丝孔滑牙 | 孔径偏大 / 扭力过大 | 缩小孔径 0.2 mm，或改热熔铜螺母 |
| 装配后共振异响 | 刚性连接、无减振 | 加减振垫，增加壁厚或加强筋 |
| 风量明显偏小 | 开孔率不足、风道堵塞 | 提高开孔率，缩短风道 |
| 翘边 | 热床附着差、冷却过强 | 首层降速、加裙边 |
