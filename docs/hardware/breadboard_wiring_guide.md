# 桌面智能风扇原型机 —— 面包板逐模块接线指南 (Rev B4)

> **硬件基准**：STM32F103C8T6 最小系统核心板（BluePill）+ `fan_ctrl_revB` PCB 实际网络依据（`native_pin_nets.json`）  
> **固件状态**：全功能操作固件已就绪（包含 25kHz 超声频电机调速、360° 连续舵机调速、I2C 共享总线、ASR-PRO 语音交互、EC11 硬件正交编码器、消抖双按键、DHT11 温湿度、PAJ7620 手势识别与串口 CLI）  
> **文档用途**：指导在标准双轨面包板上进行实物原型搭建、连线自检与逐模块功能验证。

## 一、 面包板电源与接地总线规划（至关重要）

动力执行器件（130 直流电机、MG90S 舵机）以及 ASR-PRO 语音功放在运行瞬间会产生 **0.5A ~ 1.5A** 的瞬态峰值电流。  
> [!CAUTION]
> **绝对禁止从单片机 3.3V 引脚为电机或舵机供电！**  
> 必须准备一组外接独立 **5V 稳压电源（额定输出建议 ≥ 2A）**，并在面包板上实施“动力/逻辑分轨、全系统共地”布线：

```
                              【面包板双电源轨拓扑图】

  外部 5V 稳压电源 (≥2A) ──┬──> 面包板红色电源轨 (+5V 动力轨) ──> TB6612 (VM)
                           │                                   ──> MG90S 舵机 (红色线 5V)
                           │                                   ──> ASR-PRO 语音板 (5V)
                           │                                   ──> 有源蜂鸣器 (VCC 5V)
                           │
                           └──> STM32 核心板 5V 引脚 (供给核心板板载 3.3V LDO)
                                    │
                                    └──> STM32 3.3V 引脚 ──> 面包板黄色逻辑轨 (+3.3V)
                                                                 ──> 0.96" OLED (VCC)
                                                                 ──> PAJ7620 手势 (VCC，严禁接5V)
                                                                 ──> DHT11 传感器 (VCC)
                                                                 ──> EC11 编码器 (VCC)
                                                                 ──> TB6612 逻辑端 (VCC)

  系统公共地 (GND) ────────┴──> 面包板蓝色接地轨 (GND 总线) ───> 所有模块 GND 必须牢固连通共地！
```

## 三、 实物极易踩坑的“针序避坑指南”

1. **DHT11 模块针序混淆**：
   - 市场上散件 DHT11 小板通常有 3 针，但不同厂家针序并不一致（常见有 `[S, +, -]` 与 `[+, S, -]` 两种）。
   - **接线前务必仔细看清小板正反面的印刷丝印**：
     - 标有 `+` 或 `VCC` 的引脚接 3.3V；
     - 标有 `-` 或 `GND` 的引脚接公共地；
     - 标有 `S`、`OUT` 或 `DAT` 的引脚接单片机 **PB9**。
2. **0.96 寸 OLED 显示屏针序**：
   - 常见 4 针 I2C OLED 有两种线序：
     - 版本 A：`GND, VDD, SCK, SDA`（最常见）
     - 版本 B：`VCC, GND, SCL, SDA`
   - **绝不能仅凭插针位置盲插，务必对准屏幕顶部的文字丝印**！插反 VCC 与 GND 会立即烧毁屏幕驱动 IC。
3. **MG90S 舵机三线颜色**：
   - 绝大多数舵机出厂线序为：**棕色/黑色（GND）、红色（5V 动力）、黄色/橙色（PWM 信号，接 PB8）**。
4. **EC11 旋转编码器 (带 VCC, GND, A, B, C)**：
   - 您的 5 脚模块丝印为 `VCC, GND, A, B, C` 时：
     - `A` 接 **PA6**，`B` 接 **PA7**；
     - `VCC` 接 3.3V，`GND` 接 GND；
     - **`C` 脚就是旋钮下按按键 (Click / SW)**，请使用一根杜邦线将 **`C` 接到 STM32 的 PB12**。按下旋钮即可在手动调速模式与自动温控模式之间即时切换。
5. **I2C 双从机共用总线**：
   - 0.96" OLED（从机地址 `0x3C`）与 PAJ7620 手势识别模块（从机地址 `0x73`）在物理上为并联结构。
   - 将 OLED 的 SCL 和 PAJ7620 的 SCL 插在面包板同一行，再引一根杜邦线连到 STM32 的 **PB6**。
   - 将两者的 SDA 插在面包板同一行，再引一根杜邦线连到 STM32 的 **PB7**。
   - 若模块本身未内置上拉电阻，建议在 SCL 和 SDA 线上分别接一颗 4.7kΩ 电阻上拉到 3.3V 逻辑轨。

## 五、 接线完成后的上电自检流程

1. **万用表通断与阻抗档核验（未通电时）**：
   - 测量面包板 +5V 动力轨与 GND 之间，确认无蜂鸣短路现象。
   - 测量面包板 +3.3V 逻辑轨与 GND 之间，确认无短路现象。
   - 测量 TB6612 的 VM 与 VCC 之间，确认两者未在面包板上发生短接。
2. **首次通电核验**：
   - 接入 5V 稳压电源，观察电源指示灯是否正常点亮，手触各模块芯片（STM32、TB6612、PAJ7620）表面，确认无异常发烫。
3. **通知开始烧录**：
   - 当确认物理线路连接牢固、各模块极性无误后，即可在对话中通知工程师执行固件烧录。
