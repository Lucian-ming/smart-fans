# 引脚分配与外设映射表 (Rev B4)

> 版本：v4.0（STM32F103 蓝板主控 + TB6612FNG 130直流电机驱动 + MG90S 舵机 + ASR-PRO 免唤醒语音 + PAJ7620 手势 + EC11 编码器 + 2 个带帽大按键 + 0.96" OLED + DHT11 温湿度）
> 主板规格：**95.0 × 95.0 mm（R=3.0 mm 圆角，85.0 × 85.0 mm M3 安装孔距，嘉立创免费券合规）**
> 主控方案：**STM32F103C8T6 最小系统核心板（双排 2.54 排母直插，USB 朝北/后）**
> 外设分配原则：**定时器零冲突，硬件正交编码器 (TIM3)、舵机 50Hz PWM (TIM4)、130 电机 25kHz PWM (TIM2)、ASR-PRO 语音 (USART2)、I2C1 总线 (PB6/PB7) 各占独立硬件资源，零插接短路风险**。

## 2. 定时器与外设分配无冲突审查

- **TIM2 (通用定时器)**：专职于 `PA0` 产生 **25.0 kHz** 标准高频 PWM 驱动 130 电机，无音频啸叫。
- **TIM3 (通用定时器)**：专职于硬件正交编码器解码模式 (`PA6`/`PA7`)，硬件自动增减计数器，旋钮调速零延迟。
- **TIM4 (通用定时器)**：专职于 `PB8` 产生 **50 Hz (周期 20ms)** 标准脉冲，驱动 MG90S 舵机 0°~90° 平滑扫风。
- **I2C1**：`PB6`/`PB7` 挂载 OLED (`0x3C`) 与 PAJ7620U2 (`0x73`)，从机地址完全隔离，板载独立 4.7kΩ 上拉电阻。
- **USART2**：专职于 `PA2`/`PA3` 与 ASR-PRO 离线语音芯片全双工通信。
