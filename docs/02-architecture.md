# 系统架构

> 版本：v0.3（12 V DC PWM 风扇 + STM32F103C8T6 + 语音/手势，v1 不联网） · 2026-11-03

## 1. 总体框图

```
   12V 适配器

       ▼
```

## 2. 模块划分

| 模块 | 职责 | 关键接口 |
| --- | --- | --- |
| 电源模块 | 输入保护、12 V→5 V→3.3 V、去耦 | 12 V / 5 V / 3.3 V |
| 风扇接口 | 接收 PWM 驱动信号，回传 FG 转速 | TIM2_CH1 输出、TIM1_CH1 捕获 |
| 主控 | 采样、控制律、状态机、串口命令 | 各外设 |
| 温度采集 | DS18B20 单总线读取 | PA1 + 微秒延时 |
| 人机交互 | 编码器/按键输入、OLED 显示、蜂鸣提示 | TIM3、I2C1、GPIO |
| 语音交互 | 接收语音模块识别的词条，触发动作；反向发送播报指令 | USART2（3.3 V TTL） |
| 手势识别 | 读取 PAJ7620 手势事件（上/下/左/右/顺逆时针等） | I2C1 + EXTI（INT 引脚） |
| 调试接口 | 串口日志 + 文本命令，SWD 烧录 | UART1、SWD |

## 3. 固件分层

```
src/
├── main.c            初始化 + 主循环（只做调度）
├── stm32f1xx_it.c    中断向量
├── config/           引脚、版本、参数
├── hal/              PWM / 捕获 / I2C / ADC / UART 薄封装（换芯片只改这里）
├── drivers/          风扇、DS18B20、OLED、编码器、蜂鸣器
└── app/              温控、状态机、参数存储、串口命令
```

原则：**app 层不直接调 HAL**，只依赖 hal/drivers 接口 —— 逻辑可在 PC 上用 `native` 环境做单元测试。

## 4. 温控策略（初版）

- 输入：当前温度 T、目标温度 T_set、滞回带 H = 0.5 ℃
- 分级映射（T_set ~ T_set+5 ℃ → 占空比 25% ~ 100%），每 1 s 更新一次
- 变化率限幅：≤ 10 %/s，避免转速突变引起的噪声与电流冲击
- 启动软启动：从 0 斜坡到目标占空比，用时约 1 s
- 低温默认：T < T_set − H 时停转；可通过参数改为维持最低档

## 5. 状态机

```
       ┌────────┐  按键/命令      ┌────────┐
       │  IDLE  │───────────────▶│ MANUAL │
       └───┬────┘◀───────────────└───┬────┘
           │ T ≥ T_set+H            │ 命令切自动
           ▼                        ▼
       ┌────────┐  堵转/传感器故障 ┌────────┐
       │  AUTO  │────────────────▶│ FAULT  │
       └────────┘◀──复位/自恢复────└────────┘
```

- FAULT 时停 PWM 输出、OLED 显示故障码、蜂鸣器间歇报警
- 堵转判定：占空比 > 10% 但 FG 连续 3 s 无脉冲

## 6. 关键约束

- **PWM 频率 25 kHz**：避开可听频段；TIM2 时钟 72 MHz → PSC=71、ARR=39 得 25 kHz
- **4-pin 风扇 PWM 逻辑电平为 5 V**：建议用 NPN 开漏反相驱动（固件里占空比取反），PCB 预留直连跳线
- **FG 为开漏输出**：必须上拉到 3.3 V，不能悬空
- 12 V 功率回路按 2 A 峰值设计：铜宽 ≥ 1.5 mm，回路面积尽量小
- 风扇启动电流约为稳态 2–2.5 倍，电源与储能电容按此留余量，避免 MCU 复位
- OLED 与 DS18B20 共用 3.3 V，注意 I²C 上拉不要超过 4.7 kΩ（省电）
- **语音模块**用 5 V 供电（内部 LDO），UART 为 3.3 V TTL；喇叭播报瞬间电流大，喇叭线远离 I²C 与 FG 走线，必要时给模块电源加 100 µF 储能
- **语音/手势事件只在主循环处理**，中断里只置标志，避免在 ISR 里改状态机或写 I²C
- 手势识别需在壳体上开窗口，窗口不能被外壳遮挡，PAJ7620 与 I²C 走线加地包围
