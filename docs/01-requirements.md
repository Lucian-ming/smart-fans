# 需求文档

> 版本：v0.2 · 日期：2026-11-03
> 状态：**选型已确认**（12 V DC 4-pin PWM 风扇 + STM32F103C8T6，v1 不联网）。标注「待确认」的验收指标待实测后转「通过」。

## 1. 产品目标

用一台风扇实现「温度驱动 + 语音 + 手势 + 按键」的多模智能送风：
- 环境温度高于设定阈值时自动启动并随温差上调转速；
- 用户可用按键/编码器、语音口令或挥手手势控制开关与档位；
- 屏幕实时显示温度、档位、模式与告警；
- v1 不联网，远程控制留到 v2。

## 4. 已确认选型

2026-11-03 已确认，后续按此推进；如需变更，同步更新本表、`docs/hardware/pinmap.md` 与固件配置。

| 项目 | 决定 | 说明 |
| --- | --- | --- |
| 风扇 | **12 V DC 4-pin PWM**（如 12025 机箱风扇） | 低压安全；PWM 25 kHz 调速，FG 反馈转速 |
| 主控 | **STM32F103C8T6**（LQFP48，64 KB Flash / 20 KB RAM） | 裸机 + STM32Cube HAL，PlatformIO 开发 |
| 温度传感器 | **DS18B20**（单总线，PA1） | 精度 ±0.5 ℃，无需校准；备选 NTC + ADC |
| 人机交互 | **旋转编码器 + 0.96" OLED（I²C）** | 编码器带按键；OLED 显示温度/档位/告警 |
| 保护 | **堵转检测 + 传感器故障 + 过温告警** | FG 连续 3 s 无脉冲判定堵转，蜂鸣器 + OLED 提示 |
| 语音模块 | **SU-03T 或 ASR-PRO**（离线识别，UART 输出） | 支持自定义词条；UART2 连接，词条与播报在厂商平台配置 |
| 手势传感器 | **PAJ7620U2**（I²C，9 种手势） | 与 OLED 共用 I²C1 总线（地址 0x73），INT 接 PA4 |
| 供电 | **12 V/2 A 适配器 → 降压 5 V → LDO 3.3 V** | 风扇与逻辑共用 12 V，需软启动避免跌落复位 |
| 联网 | **v1 不做**（无 Wi-Fi/BLE） | 仅保留 UART1 调试与命令接口，v2 再评估 |

## 5. 明确不做（v1 范围外）

- 联网与远程控制（Wi-Fi / BLE / App 均不在 v1）
- 摄像头/视觉人体检测（手势用专用传感器，不做图像识别）
- 电池供电与便携形态
- 多台风扇联动
- 量产认证（CE/FCC）

## 6. 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 220 V AC 方案安全风险 | 人身与设备安全 | 优先选 12/24 V DC；若必须 AC，使用隔离电源模块 + 强电区物理隔离与爬电距离 ≥ 6 mm |
| 风扇启动电流大 | 电源跌落导致 MCU 复位 | 电源留 2 倍余量，软启动，加足够储能电容 |
| PWM 噪声/啸叫 | 体验差 | PWM 频率选 20–25 kHz 避开可听频段，必要时加 LC 滤波 |
| 外壳与 PCB 尺寸不匹配 | 返工重画 | 先冻结 PCB 外形与安装孔，再开外壳 |
