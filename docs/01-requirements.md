## 1. 产品目标与交互体系

用一台高性价比、高颜值的立式桌面智能台扇，实现「温度感知 + 非接触手势 + 免唤醒语音播报 + 旋钮无级调速 + 多按键直控 + 自动摇头」：

1. **结构形态**：
   - 分体立式台扇，底座内置控制主板、0.96" OLED、EC11 旋转编码器与按键、ASR-PRO 语音模块及 2W 腔体扬声器；
   - 底座前面板采用 **20°~30° 舒适仰角设计**，仰对坐姿人眼与操作手势；
   - 立柱通过 **MG90S 金属齿轮舵机** 带动标准 **12025 (12cm) 4-Pin 机箱风扇** 实现 0°~90° 左右平滑扫风。
2. **纯机身多按键极佳操控**：
   - **EC11 旋转编码器**：顺时针/逆时针旋转无级平滑调节风速（0%~100% PWM 占空比）；
   - **按键 1（编码器中键 PB12）**：单击启停风扇电源（On / Off）；
   - **按键 2（独立按键 PB13）**：模式切换按键（在「手动无级模式」与「自动温控模式」之间切换）；
   - **按键 3（独立按键 PB15）**：摇头控制按键（循环切换「停止 / 45° 聚焦扫风 / 90° 宽幅扫风」）；
   - **按键 4（独立按键 PB0）**：辅助按键（短按切换蜂鸣器静音模式 / 长按定时关机）。
3. **9 种非接触光学手势（PAJ7620U2）**：
   - **向上挥手**：风速增加 10%（伴随一次轻微蜂鸣提示）；
   - **向下挥手**：风速降低 10%；
   - **向右挥手**：开启摇头；
   - **向左挥手**：停止摇头并保持当前朝向；
   - **向前靠近 (Push)**：风扇开机；
   - **向后远离 (Pull)**：风扇关机。
4. **离线免唤醒语音（ASR-PRO + 8Ω 2W 腔体扬声器）**：
   - 支持高频常用口令**免唤醒词直接响应**：“开风扇”、“关风扇”、“大风”、“小风”、“开始摇头”、“停止摇头”、“自动模式”、“静音模式”；
   - 扬声器清晰语音对答播报确认（“风扇已开启”、“风速已提高”、“已开启自动温控”等）。
5. **智能闭环温控（DS18B20 数字单总线）**：
   - 线性温控曲线：以 26℃ 为起始温度（对应 25% 起转风速），32℃ 为满速温度（对应 100% 满速），中间线性平滑插值；
   - 低温自动停转：环境温度低于 26℃ 时自动停机休眠，具备 0.5℃ 滞回防频繁启停；
   - 风速变化平滑滤波：每秒风速变化率限幅 ≤ 10%，避免转速突变引起啸叫与气流冲击。
6. **0.96" OLED 微光时钟防烧屏策略**：
   - 正常工作时全功能仪表界面：显示环境温度、PWM 占空比%、FG 测量真实转速 (RPM)、工作模式与摇头状态；
   - **微光时钟模式**：无交互操作持续 30 秒后，自动将 OLED 对比度降低至 10%，精简显示当前时钟与温度（防止静态画面烧屏，减少桌面光污染）；
   - 任意手势挥动、语音口令、旋钮旋转或按键按压，立即秒级唤醒恢复高亮全功能仪表盘。
7. **真实转速监控与堵转保护**：
   - TIM1 输入捕获 12025 风扇的 FG 脉冲，精确计算转速；
   - 开启输出且占空比 > 15% 时，若连续 3 秒无 FG 脉冲，立即切断 PWM 输出，蜂鸣器长鸣报警，并在屏幕显示 `FAULT: STALL`。
