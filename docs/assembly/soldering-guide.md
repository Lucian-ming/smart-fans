# 焊接指南

> 适用：12 V DC 方案的 revA 板（贴片 + 插件混合）。首板务必**分块焊接、分块上电**。

## 1. 准备

**工具**：恒温烙铁（320–350 ℃，刀头/尖头各一）、热风枪（拆贴片用）、助焊剂、吸锡带、放大镜/显微镜、万用表、可调电源（限流 0.2 A 起）。

**物料**：按 `hardware/fabrication/bom/` 的 BOM 备料，先按封装分堆：0402/0603 电阻电容、SOP/SOT 芯片、插件（排针、端子、电解电容）。

**检查**：核对器件型号与极性（二极管、电解电容、LED、IC 的 1 脚标记），封装与 PCB 丝印一致。

## 2. 焊接顺序

1. **先矮后高**：电阻 → 电容（先小容值贴片，后电解）→ 二极管 → 三极管/MOSFET → IC → 插件。
2. **先小后大**：0402/0603 先，SOP/QFN 后，最后接插件与电解电容。
3. **先电源后信号**：电源部分焊完先测电压，再焊 MCU 与外围。
4. **敏感器件最后**：MCU、传感器、OLED 排座在电源验证通过后焊接。

### 关键器件注意

| 器件 | 要点 |
| --- | --- |
| QFN/DFN | 先上锡膏或薄锡，热风 300 ℃ 吹 20–30 s，轻推复位，冷却后再测 |
| 电解电容 | 极性（白条为负），反接会鼓包 |
| 二极管 | 丝印横线为阴极 |
| MOSFET | 注意 G/D/S 顺序，栅极串阻不可省 |
| 排针/端子 | 先固定对角两点再焊其余，避免歪斜 |
| OLED 排座 | 对齐后再焊，禁止带板弯折 |

## 3. 分块上电检查

| 步骤 | 操作 | 期望 |
| --- | --- | --- |
| 1 | 不上电，测 12 V 输入对地阻抗 | > 1 kΩ，无短路 |
| 2 | 限流 0.1 A 上 12 V，测 5 V 轨 | 4.9–5.1 V，电流 < 50 mA |
| 3 | 测 3.3 V 轨 | 3.25–3.35 V |
| 4 | 焊 MCU，上电测 3.3 V 纹波 | 峰峰值 < 100 mV |
| 5 | ST-Link 烧录骨架固件，观察 LED 与串口 | LED 0.5 s 闪烁，串口打印版本号 |
| 6 | 接风扇，PWM 10% 起逐步加 | 转速平滑上升，无异响，MOSFET 不烫 |

**任何一步异常立刻断电**，先查短路与极性，不要"再试一次"。

## 4. 常见问题排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 3.3 V 偏低/抖动 | LDO 输入不足、输出电容缺失、负载过大 | 测输入、补 10 µF、断开负载定位 |
| MCU 反复重启 | 电源跌落、NRST 受扰、看门狗误触发 | 加储能电容、NRST 上拉 10 kΩ + 100 nF |
| 风扇不转 | PWM 无输出、MOSFET 未导通、风扇线序错 | 示波器看栅极、测 Vds、核对线序 |
| 风扇啸叫 | PWM 频率落在可听区、机械共振 | 改 25 kHz、加减振垫 |
| 烧录失败 | BOOT0 未置低、SWD 接触不良、ST-Link 驱动、目标板未供电 | 确认 BOOT0=0、重插 SWD、先给板子独立供电 |

## 5. 首板验收清单

- [ ] 所有器件焊接无虚焊、连锡、立碑
- [ ] 各电压轨正常且纹波达标
- [ ] 烧录成功，串口有启动日志
- [ ] 传感器读数合理（室温 20–30 ℃）
- [ ] 风扇 0/25/50/100% 四档均正常
- [ ] 连续运行 30 min 无异常发热
- [ ] 拍照存档到 `docs/logs/assets/`
