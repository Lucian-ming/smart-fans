# KiCad 工程约定

## 1. 新建工程

1. 打开 KiCad → 新建工程，保存到本目录：`fan_ctrl_revA.kicad_pro`
2. 原理图 `fan_ctrl_revA.kicad_sch`、PCB `fan_ctrl_revA.kicad_pcb` 会自动生成
3. 自建符号放 `libs/symbols/`，自建封装放 `libs/footprints/`，在工程里添加为项目库

> 本目录当前只有说明文件，工程文件需在 KiCad 中创建（避免出现打不开的空壳文件）。

## 2. 命名与版本

- 工程名：`fan_ctrl_revX`（X 从 A 开始，每投板一次 +1）
- 改版不改文件名中的小版本，用 Git 提交记录区分；重大改版才升 rev
- 网络命名：`功能_极性`，如 `FAN_PWM`、`FAN_TACH`、`V12`、`V33`、`GND`、`TEMP_DATA`

## 3. 原理图规范

- 按功能分区画：电源、MCU、风扇驱动、传感器、交互、接口；用图框与文字标注分区
- 每个电源轨标注电压与最大电流
- 去耦电容画在对应 IC 电源脚旁，不要集中堆在别处
- 关键网络加标签，方便 PCB 与固件对照
- ERC 必须 0 错误；警告逐条确认可接受原因

## 4. PCB 规范（默认 2 层，1 oz）

- 板框按外壳与风扇孔位反推，**尺寸先冻结再布线**
- 安装孔：φ3.2 mm（M3 螺丝）；定位孔 φ3.2 或按定位柱直径
- 12 V 功率回路：铜宽 ≥ 1.5 mm，回路面积小，避免长细走线
- 地：底层整块铺地，数字/模拟分区，风扇大电流地单点汇入
- PWM 走线远离模拟与传感器信号，必要时包地
- 丝印：板名 + rev + 日期、接插件功能、LED 极性、1 脚标记；字高 ≥ 0.8 mm
- DRC 0 错误；3D 视图检查器件与外壳干涉

## 5. 导出（投板前）

1. `文件 → 制造输出 → Gerber`：选 RS-274X，单位 mm，层：F.Cu/B.Cu/F.SilkS/B.SilkS/F.Mask/B.Mask/Edge.Cuts，钻孔单独导出（Excellon）
2. `工具 → 生成 BOM`（或 BOM 插件），字段含：位号、数量、型号、封装、备注
3. 需要贴片时导出坐标文件（Centroid / Pick&Place），原点统一设为左下角
4. 全部放入 `hardware/fabrication/revX_日期/`

## 6. 提交前检查

- [ ] 原理图与 PCB 已同步（Update PCB from Schematic，无未同步项）
- [ ] DRC 0 错误，丝印无遮挡
- [ ] Gerber 用查看器逐层看过（尤其阻焊开窗与板框）
- [ ] BOM 数量与原理图一致，位号无重复
- [ ] 版本号与日期已更新到丝印
