# 单5V版PCB打样验收报告

**状态：修复后14项独立检查全部通过，仅作单5V版本少量裸板首轮打样交付；不是整机适配或量产认证。**

## 版本范围

本次按用户后续决定将原12V降压方案改为母板单5V输入。PCB为95×95mm、双层、R3圆角。交付范围仅PCB、原理图、Gerber/钻孔、BOM和安装/验收说明；旧外壳STL和旧嘉立创项目不代表本次布局，不一并声称适配。

### 已实施设计变更
- 单5V端子输入，保险丝和PMOS反接保护；取消XL1509及其降压支路，电机/舵机不经STM32开发板转供电。
- 核心板40针按用户本地Altium/PDF资料修正非镜像布局，R20接地，开发板与母板3V3输出不并联。
- TB6612排距15mm及左右针序、编码器21mm组距与VCC/GND、A/C/B顺序采用用户实测；编码器无独立SW，取消原虚构连线。
- ASR按用户确认25.4mm排距、两排各8针，采用UART1，设置供电/TX/RX三跳帽隔离。
- 修正二极管K/A编号、SOT-223重复电源焊盘编号和真实尺寸；连接器电机/喇叭两针为2.50mm；删除孤立MIC接口。
- 铜区按通孔铜外径而非钻孔径避让；双层避障路由纳入异网铜净距、所有钻孔孔间距、功率主干与盖油孔边要求。
- 所有位号、安全文字、边框与Gerber丝印共用几何；过孔双面盖油，实际焊盘阻焊开窗不得侵入盖油孔保护范围。

## 下单与上电边界

即使自动检查全部通过，范围也仅是本设计文件的独立电气连通与理想制造几何检查：
1. 未执行KiCad原生DRC/ERC或原生网表导出；不把自编检查称为原生工具签核。
2. TB与编码器尺寸为用户粗测，须试插；OLED后移/反向安装为本版明确安装条件，并非实物板框及针排到边距离已经验证。
3. 尚未验证完整模块堆叠、整机外壳、线束、螺钉操作空间、温升、真实启动/堵转电流与保险分断能力。
4. 库存未实时核验；BOM型号匹配不等于现货或自动贴装库保证。模块排母/自定义接口需按安装要求采购。
5. 输入仅5V；ASR烧录须断开三跳帽；STM32 USB调试须执行供电隔离并避免GPIO反向供电。喇叭为BTL，不能把其中一端接地。

因此只能先做少量功能样板、限流上电、试装与测试，不能据本报告直接批准整机量产。具体安装约定见[打样安装说明](<D:/smart_fans/hardware/fabrication/RevB_5V_Prototype_Notes.md>)。只使用新建的RevB_5V独立交付目录；下载根目录的旧12V文件继续禁用。
