## 1. 电源与配电网络 (Power Distribution)

### 1.1 12V 外部直流输入与防反接
```
DC-005 (DC1)                  D2 (SS24)
  Pin 1 (12V) ───────────────▶|────────┬───────────▶ +12V_RAW (至风扇与降压)
                                       │
  Pin 2,3 (GND) ───────────────────────┴───────────▶ GND
                                       │
                                     C1, C2 (100µF/25V 电解) + C7 (100nF)
```
- **DC1**：DC-005 母座（5.5×2.1 mm 直插）；
- **D2**：SS24 贴片肖特基二极管（40V 2A，正向压降约 0.4V），防止电源插反损坏板卡；
- **C1, C2**：100 µF / 25V 铝电解电容（贴片 6.3×7.7 mm 或直插），吸收风扇高频纹波；
- **C7**：100 nF 0805 陶瓷贴片电容，滤除高频杂波。

### 1.2 12V → 5.0V / 2A 降压转换器 (XL1509-5.0)
```
          +12V_RAW
             │
             ├── Pin 1 (VIN)    XL1509-5.0 (U2)
             │
             ├── Pin 2 (OUTPUT) ──┬───[ L1: 47µH ]───┬────────▶ +5V
             │                    │                  │
             │                 D1 (SS24)          C3, C4 (220µF/16V)
             │                    │ 阴极接Pin2       │ + C8 (100nF)
             │                    ▼ 阳极接GND        │
             │                                    R1 (1k) ──▶ LED4 (绿) ──▶ GND
             ├── Pin 3 (FEEDBACK) ───────────────────┘ (固定5V无需分压电阻)
             │
             ├── Pin 4 (ON/OFF) ─────────────────────▶ GND (常开使能)
             └── Pin 5~8 (GND) ──────────────────────▶ GND
```
- **U2**：XL1509-5.0 开关稳压 IC（SOP-8），开关频率 150 kHz，连续输出电流 2A；
- **L1**：47 µH 贴片功率电感（CD54 或 7×7 mm 屏蔽电感，额定电流 ≥ 1.5A）；
- **D1**：SS24 肖特基续流二极管（紧贴 Pin 2 与 GND 焊盘走线）；
- **C3, C4**：220 µF / 16V 铝电解电容，储能充足，确保扬声器 2W 语音播报与舵机摆头时 5V 电压不跌落；
- **LED4**：0805 绿色指示灯，串联 1 kΩ 限流电阻作为 5V 正常供电指示。

### 1.3 5.0V → 3.3V 低压差线性稳压器 (AMS1117-3.3)
```
   +5V ────────┬────────▶ Pin 3 (VIN)   AMS1117-3.3 (U3)
               │
            C5 (10µF)
               │
             Pin 1 (GND) ─────────────────────────────▶ GND
               │
             Pin 2/Tab (VOUT) ──┬──────────┬──────────▶ +3.3V
                                │          │
                             C6 (10µF)  R2 (1k)
                                │          │
                               GND        LED5 (蓝)
                                           │
                                          GND
```
- **U3**：AMS1117-3.3 稳压器（SOT-223），最大输出电流 1.0A；
- **C5, C6**：10 µF 0805 X5R 贴片陶瓷电容；
- **LED5**：0805 蓝色指示灯，串联 1 kΩ 限流电阻作为 3.3V 逻辑电源就绪指示。

## 2. 主控核心与模块接口设计 (MCU & Sockets)

### 2.1 STM32 蓝板直插排母 (J1, J2)
采用双排 1×20P 2.54mm 排母，蓝板正向插装：

| 蓝板引脚 | 信号网络名称 | 连接目标与外设说明 |
| :--- | :--- | :--- |
| **PA0** | `FAN_PWM` | 经 100Ω 电阻 (R9) 连接至 4-Pin 风扇插座 Pin 4 (TIM2_CH1) |
| **PA1** | `TEMP_DATA`| 连接 DS18B20 测温脚，带 4.7kΩ (R3) 上拉至 3.3V |
| **PA2** | `VOICE_TX` | 连接至 ASR-PRO 语音板 RX (USART2_TX) |
| **PA3** | `VOICE_RX` | 连接至 ASR-PRO 语音板 TX (USART2_RX) |
| **PA4** | `GESTURE_INT`| 连接至 PAJ7620U2 中断脚，带 10kΩ (R8) 上拉至 3.3V |
| **PA6** | `ENC_A` | 连接至 EC11 旋转编码器 A 相 (TIM3_CH1 正交解码) |
| **PA7** | `ENC_B` | 连接至 EC11 旋转编码器 B 相 (TIM3_CH2 正交解码) |
| **PA8** | `FAN_TACH` | 4-Pin 风扇 FG 转速脉冲输入，带 4.7kΩ (R6) 上拉至 3.3V (TIM1_CH1) |
| **PA9** | `DEBUG_TX` | 固件调试串口 TX (USART1_TX)，引出 2.54 排针 |
| **PA10**| `DEBUG_RX` | 固件调试串口 RX (USART1_RX)，引出 2.54 排针 |
| **PB0** | `BTN_AUX` | 独立按键 3（静音/定时），按下接 GND，MCU 内部上拉 |
| **PB6** | `I2C1_SCL` | 硬件 I2C 时钟，连接 OLED 与 PAJ7620U2，带 4.7kΩ (R4) 上拉 |
| **PB7** | `I2C1_SDA` | 硬件 I2C 数据，连接 OLED 与 PAJ7620U2，带 4.7kΩ (R5) 上拉 |
| **PB8** | `SERVO_PWM`| 连接 MG90S 舵机信号线，输出 50Hz PWM (TIM4_CH3) |
| **PB12**| `ENC_SW` | EC11 旋钮中键按压（开关机），按下接 GND，MCU 内部上拉 |
| **PB13**| `BTN_MODE` | 独立按键 1（手动/自动模式），按下接 GND，MCU 内部上拉 |
| **PB14**| `BUZZER_CTRL`| 经 1kΩ 电阻 (R1) 驱动 Q1 (S8050) 基极，发声提示 |
| **PB15**| `BTN_SWING` | 独立按键 2（摇头控制），按下接 GND，MCU 内部上拉 |

## 3. 外设接口与执行机构原理

### 3.1 12025 电脑机箱风扇接口 (FAN1)
标准 2.54mm 4-Pin 防呆插座（KF2510-4P 直插公座）：
- **Pin 1 (GND)**：主地回路（铜宽 ≥ 1.5 mm）；
- **Pin 2 (12V)**：接 `+12V_RAW`（铜宽 ≥ 1.5 mm）；
- **Pin 3 (TACH / FG)**：风扇转速脉冲开漏输出，经 4.7kΩ 上拉至 3.3V，连至 `PA8`；
- **Pin 4 (PWM)**：风扇 25kHz 调速输入，经 100Ω 缓冲电阻连至 `PA0`。

### 3.2 备用 2-Pin 直流风扇接口 (FAN2)
- **Pin 1 (12V)**：接 `+12V_RAW`；
- **Pin 2 (DRAIN)**：接 Q2 (AO3400A) 漏极，栅极经 100Ω 电阻接 `PA0`，栅极对地加 10kΩ 关断下拉。

### 3.3 MG90S 金属齿轮舵机接口 (SERVO1)
标准 1×3P 2.54mm 直插排针：
- **Pin 1 (GND)**：接系统地；
- **Pin 2 (+5V)**：接稳压后的 `+5V` 功率总线；
- **Pin 3 (PWM)**：接单片机 `PB8`（TIM4_CH3 产生 50Hz 脉宽调制信号）。

### 3.4 0.96 寸 I2C OLED 显示屏插座 (J5)
1×4P 2.54mm 单排排母：
- **Pin 1 (GND)**：接地；
- **Pin 2 (VCC)**：接 `+3.3V`；
- **Pin 3 (SCL)**：接 `PB6` (带 4.7k 上拉)；
- **Pin 4 (SDA)**：接 `PB7` (带 4.7k 上拉)。

### 3.5 PAJ7620U2 光学手势传感器插座 (J6)
1×5P 2.54mm 单排排母：
- **Pin 1 (VCC)**：接 `+3.3V`；
- **Pin 2 (GND)**：接地；
- **Pin 3 (SCL)**：接 `PB6`；
- **Pin 4 (SDA)**：接 `PB7`；
- **Pin 5 (INT)**：接 `PA4` (带 10k 上拉)。

### 3.6 ASR-PRO 离线语音核心板插座 (J3, J4)
2× 1×8P 2.54mm 排母：
- 供电脚：Pin 接 `+5V` 与 `GND`；
- 通信脚：`TX` 接单片机 `PA3 (USART2_RX)`，`RX` 接单片机 `PA2 (USART2_TX)`；
- 音频接口：引出 `SPK+` / `SPK-` 接 2-Pin 扬声器插座 (SPK1)，引出 `MIC+` / `MIC-` 接 2-Pin 拾音插座 (MIC1)。

### 3.7 EC11 旋转编码器与独立按键 (SW1, KEY1~KEY3)
- **SW1 (EC11)**：A相接 `PA6`，B相接 `PA7`，C公共脚接 `GND`，按压键接 `PB12`；
- **KEY1 (模式切换)**：接 `PB13` 与 `GND`；
- **KEY2 (摇头控制)**：接 `PB15` 与 `GND`；
- **KEY3 (辅助静音)**：接 `PB0` 与 `GND`。

### 3.8 蜂鸣器驱动电路 (BZ1, Q1)
- **BZ1**：5V 有源微型蜂鸣器，正极接 `+5V`，负极接 Q1 漏极/集电极；
- **D3**：1N4148 反向并联在蜂鸣器两端，吸收断开瞬间的高压反峰；
- **Q1**：S8050 NPN 三极管，基极接 1kΩ (R1) 连至 `PB14`，基极对地并联 10kΩ (R7) 下拉电阻。
